### Derived witness-native schedule

The schedule state is a tuple `q = (class nuclei, persistence pairs, annulus debt, per-edge flip mass, τ rung, eikonal defect, pose basin, rate marginal)`. Epoch is only a cap. Loss weights change only on accepted state boundaries.

1. **S0 — deterministic initialization and custody.** Build structured core, island seed, pose carrier, and the exact R operator. Save a complete stage checkpoint. Gate: parser/config/manifest parity; seeded class components present through R; no optimizer step yet. All thresholds are artifact-derived; none are guessed.

2. **S1 — region and critical-nucleus formation.** Hold τ at its high, non-erasing rung; run region-forming CE/unified loss plus area dual, persistence, ladder/seed containment. Keep curvature weak enough not to remove components. Exit only when every owed class satisfies nucleus-in-flip, area-band, and persistence dwell simultaneously. A class that already passes is satisficed, not over-pushed.

3. **S2 — boundary formation.** Engage measured class-pair length geometry and annulus sensing. Require annulus slope plateau plus topology stability. Do not lower τ merely because a fixed epoch elapsed.

4. **S3 — transactional sharpening loop; repeat for every τ rung.**  
   `checkpoint A → prime λeik(τ_next) → verify no birth loss → lower τ one registered rung → engage tie-locus/chroma/screw/horizon repair → dwell → full-facet compare to A`.  
   Accept only when full score debt improves without class erasure, pose harm, or forbidden rate increase. Otherwise rollback A, mark this rung/formulation negative, and either increase retention within the measured envelope or stop. This is the direct cure for the killed arm.

5. **S3R — repair/re-anchor repeat.** If sharpening improves total dseg but one class's flip share rises beyond its pre-rung value, hold τ and repeat repair; do not advance. Recompute edge flip-mass weights only at this stage boundary, never per step. Re-anchor seed release and class-pair tension from the accepted checkpoint.

6. **S4 — Muon finish.** Fire on the existing power-law meat/conditioning criterion only after S3 topology and annulus gates are stable. Preserve the **MEASURED -32%** Muon-vs-AdamW dseg result and the already-on warm-start/final-LR anneal. Do not fire Muon into a moving ladder or a new τ rung.

7. **S5 — label-floor to appearance-phase handoff.** When label-smooth improvement reaches the canonical flicker-floor stop hook, freeze label geometry except trust-region repairs and turn on phase appearance. A negative phase treatment is scoped to its carrier/rate formulation; it cannot refute appearance phase as the only floor-crossing family.

8. **S6 — joint Seg/Pose trust region and rate close.** Keep the banked R1 dxi carrier (**MEASURED dpose 0.001610**, **MEASURED about 7.2 KB**) and admit joint updates only if the exact nonlinear pose term and dseg both obey the trust region. Post-hoc pose remains `FORMULATION: DEAD`; joint descent family remains open.

9. **S7 — terminal solve and byte-close.** Run full-P quadratic/GN where admitted, exact-metric MC, diagonal click polish, and flip-aware head offset, each with rollback. Parse back the archive, reproduce the receiver, then exact CPU/CUDA axes separately.

Fail-safe caps remain necessary but are explicitly `ASSUMED safety ceilings`, never evidence that a state gate fired. Every transition checkpoint is complete, atomic, stage-named, preserved, and registered for resume.

## §6 MULTI-BASIN SOLVE

**Answer:** yes, multi-basin terminal solving is worth doing, but random-seed multiplication is not the first choice. Use a small set of *structurally different* basins, solve each with the same exact-through-R terminal stack, and select by full archive score after parse-back. Correlated starts provide little order-statistic value.

### Protocol

Use up to **ASSUMED 4** basins, selected because they differ in representation or continuation path:

1. **B0 capacity-safe control:** corrected mod32 trunk, same transactional flow.
2. **B1 rate chart:** corrected mod19 trunk, same flow; revert by the registered **DERIVED +2%** residual rule.

The preserved stage checkpoint at epoch **MEASURED 251** is complete but already on the erasing branch. Therefore a rescue experiment must honestly distinguish `warm-start weights` from `bit-faithful resume`.

For each basin:

1. Start from a complete, provenance-stamped checkpoint.
2. Require topology stable and trailing relative dseg slope below **MEASURED policy 5e-3** before terminal solve.

### Why multiple basins can beat one

If a basin independently reaches the good terminal attraction region with probability `p`, **DERIVED** success after `N` independent starts is `1 - (1-p)^N`. Independence is **ASSUMED and likely false** for nearby seeds. For arbitrary score CDFs `Fi`, the best-score survival is **DERIVED** `P(min Si > s) = Πi (1-Fi(s))`; diversity helps only when the tails are not perfectly correlated. Therefore basin admission uses representation/trajectory diversity measured by checkpoint parameter distance *and* class-edge flip-overlap, not seed count alone.

- Per basin: up to **ASSUMED 2** LM outer steps × **ASSUMED 8** CG/HVP steps = **DERIVED 16** full-P HVP units, each independently checkpointed.
