## Verdict

The current Pact category-theory adoptions are mostly productive scaffolding, not category-theoretic results. They have helped name interfaces, expose type errors, and motivate fail-closed receipts. In the reviewed cases, however, the surviving deliverables are reproducible with ordinary typed schemas, finite algebra, quotient/setoid reasoning, relational integrity, and graph consistency checks. The formalism usually did not supply a new theorem, executable computation, or forced generalization.

One constructive transfer clears the stronger bar: residuation for a subproblem that is actually a monotone max-plus inequality. It returns the greatest feasible subsolution and an idempotent feasibility projector. That is a theorem and a computation, not a metaphor. It applies only after the live problem is proved to have the required order/supremum-preserving structure; it does not solve the non-monotone uint8/resize/scorer problem and does not minimize encoded bytes.

## The Shalizi test, made operational

Shalizi's notebook says the goal is to **“find a use for it”** and, when faced with bare formalism, **“I just don't get the point.”** His Geroch anecdote likewise rejects merely noticing that some objects “form a category” when that recognition leaves no usable result. [Shalizi, *Category Theory* notebook](https://bactra.org/notebooks/category-theory.html), fetched 2026-07-20, page SHA-256 `59cfc322143d09db3ef5d541f7a6b09dc07ef7c1007f641e4e52ec3db06f0a7a`.

For Pact, a formalism pays rent only if all of these hold:

1. **Instantiation:** the objects, morphisms, hypotheses, and equality/order notion are mapped to named local types and authority surfaces.
2. **Nontrivial yield:** the formalism supplies at least one theorem, executable computation, or forced generalization/counterexample.
3. **Counterfactual novelty:** removing the formalism would lose that yield; ordinary typed-schema review, linear algebra, group theory, or relational joins would not provide the same result just as directly.
4. **Consumer:** a named live consumer changes a build, admissibility check, solver step, or dispatch decision.
5. **Falsifiability and custody:** the claim has a scoped falsifier and either an executable receipt or an explicit `FORMALIZATION_PENDING`/custody gap.

Vocabulary, analogy, and diagrams may be good scaffolding. They are not evidence by themselves.

## Adoption audit

### #551 → #555: useful output, ordinary mechanism

The [Niu/Spivak polynomial-functor paper](https://arxiv.org/abs/2312.00990) genuinely offers a language for mode-dependent interfaces and backward replies. The local crosswalk was appropriately cautious: it denied event-loss proofs, numerical VJP correctness, fp32/uint8 commutation, authority arbitration, and numeric re-anchoring.

`src/tac/landing_diff_manifest.py` then landed a strong result: every base→head path starts unaccounted, each changed path needs an explicit merged/dropped/deferred disposition, and the receipt binds path state to Git objects and diff digests. The landing gate re-derives those facts. This is exactly the sort of kept output the project should preserve.

But the implementation consists of enums/dataclasses, path coverage, content hashes, rename/delete handling, strict JSON, and referential checks. It does not evaluate a polynomial, construct a lens, use a universal property, or derive validation completeness from the polynomial-functor semantics. The counterfactual is decisive: “enumerate the Git diff, make omission invalid, bind every disposition to content and consumer custody” is an ordinary typed-schema design. The category-theory pass helped discovery and naming; it did not uniquely determine the result.

### #554: categorical spectra do not clear the inherited bar

The crosswalk itself correctly marked stabilization-versus-residual-tower as analogy. It produced no materialized spectrum levels, connecting maps, suspension/endomorphism equivalence, invariant, exact cost, marginal, or stopping rule.

Two proposed survivors are worth retaining without the spectrum claim:

- For #452, typed source/target composition can falsify invalid tube-code compositions. That is a finite type check and must still obey the prior promotion bar: nonzero composable triples, receiver closure, exact-byte benefit, and no component-stream regression.
- The “Picard shadow” condition `phi(H_next) ⊆ H_current`, or its finite affine form `L A_next = A B`, is ordinary quotient/group compatibility. It is useful, but it does not require categorical spectra.

The tightened promotion bar is therefore:

1. materialize the levels and connecting maps;
2. state the exact equivalence or universal property being claimed;
3. compute an invariant or decision quantity that the residual-tower formulation does not already provide;
4. wire that result into #452 or another named receiver-consumed surface;
5. beat the finite typed/algebraic baseline on theorem strength, computation, or forced generalization.

Absent those five items, the spectra language should not be used as promotion evidence. This preserves the strict prior negative scope inherited from #483 without turning one failed formulation into a family-wide claim.

### #466 and #467: foundational reads that earned retention, not promotion

#466 produced several valuable exact distinctions: evaluator equivalence is a kernel setoid; quotient rate requires a constructive representative/section rather than entropy rhetoric; finite/exhaustive/well-founded searches need different certificate types; and a Pareto poset is not automatically a lattice. Its proposed `evaluator_kernel_setoid_rate_law_v1` is still a feed marked formalization pending. It is absent from `src/tac/canonical_equations`, so no executable registry or consumer currently carries the result.

#467 similarly paid as adversarial algebra review: a strict semidirect product requires a split extension; five observed classes are multiplicities, not automatically five irreducibles; the relevant module claim needs an intertwiner test; and a Galois correspondence is an anti-isomorphism only on closure-fixed objects. Its proposed `stratified_extension_orbit_rate_law_v1` is also absent from the executable equation registry. Exact archive impact and a finite receiver action remain unknown.

Both reads should stay in the knowledge base because they extinct false claims. Neither presently authorizes an implementation or promotion.

### Quadrality: a real consistency problem, not yet a category-theory implementation

`tools/graph_memory_recall.py` reconstructs a useful graph over memory, DAG, canonical equations, tasks, and deferrals. `tools/triality_drift_detector.py` is a real fail-open workflow hook that classifies file/commit patterns and complains about missing legs. These are concrete apparatus, not prose.

They do not currently establish functorial consistency. The drift detector uses regex and path heuristics; graph edges are mostly parsed references. There is no shared typed claim object whose DAG, DSL, equation, and task projections are checked for a commuting square, and no naturality law is executed. The task ledger also contains #452 but not numeric task rows for #346, #411, #466, #467, #551, #554, #555, or #572 in this checkout. The current delegation explicitly relays those identifiers, so this audit may discuss them, but the missing mirror is itself evidence that the fourth leg is not closed.

A category-theoretic reformulation becomes useful if it drives a generic checker: treat each store as a schema-indexed dataset, reindex by shared claim ID, and construct the pullback of the four legs. A claim is complete only when it induces a compatible cone; conflicting projections fail closed. [Fong and Spivak, *An Invitation to Applied Category Theory*](https://arxiv.org/abs/1803.05316) supplies the functorial-database, adjunction, and limit vocabulary. The first implementation can and should be an ordinary typed relational join. Category theory earns additional credit only when one migration/naturality law replaces multiple bespoke adapters while preserving named queries.

## Constructive harvest

### 1. Residuated max-plus solve: the one clean theorem/computation transfer

For monotone maps on complete ordered sets, a map `f` is residuated when each inequality `f(x) ≤ y` has a greatest solution `x ≤ f#(y)`. Supremum-preserving maps have such a residual; the composite gives an idempotent canonical projector onto the relevant complete subsemimodule. [Cohen, Gaubert, Quadrat, and Singer, *Max-Plus Algebra and System Theory*](https://arxiv.org/abs/math/0308166) develops exactly this residuation/projector machinery. Fong and Spivak's order-theoretic adjunction law gives the same shape: `f(p) ≤ q` iff `p ≤ g(q)`.

**Named consumer:** the monotone max-plus component of the r1b2 head/cell solve, and only that component.

**What it buys:**

- a greatest feasible subsolution rather than a heuristic candidate;
- a direct infeasibility/feasibility check through the adjunction inequalities;
- an idempotent projection, hence a canonical representative for repeated solves;
- a forced decomposition: nonmonotone resize/round/scorer constraints must stay outside the residuated core and be handled by the exact preimage solver or an outer search.

The current branch contains a preregistered tropical-residuation probe reference but no locally re-derived execution receipt for the asserted principal-solution measurement. Therefore this memo makes no measured-result claim. Before consumption, the owner must prove the live operator is monotone and sup-preserving on the stated domain, compare the residual representative under the same coder, and bind the receipt to the exact cell/problem instance. The existing `bounded_uint8_resize_preimage_cell_feasibility` equation remains the exact Diophantine authority for its bounded preimage domain.

### 2. Initial algebras for generator descriptions: good grammar discipline, no minimum-description theorem yet

Initial algebras provide induction and unique folds; terminal coalgebras provide coinduction and bisimulation for stateful behavior. [Adámek, Milius, and Moss, *Initial Algebras and Terminal Coalgebras*](https://doi.org/10.1017/9781108884112.003) gives the relevant construction.

**Named consumer:** generator-description campaign #572.

**Potential purchase:** define the legal generator grammar as an initial algebra, then implement decoder, exact byte counter, provenance collector, and admissibility verifier as folds over the same term. Structural induction can prove total coverage and compositional accounting. A coalgebraic state view can make resumable decoder equivalence testable by bisimulation.

This is not yet a rate result. Ordinary algebraic data types and recursive folds provide the same first-order engineering. It would clear the stronger bar only if the grammar admits an exact dynamic program/initiality argument for a minimum-cost description, or if the universal construction forces a generator family that the hand-written grammar omits.

### 3. Markov-category sufficiency: a useful future guard for the costate organ

[Fritz, *A synthetic approach to Markov kernels, conditional independence and theorems on sufficient statistics*](https://arxiv.org/abs/1908.07021) places conditional independence and statistical sufficiency in one compositional language.

**Named consumer:** the costate organ and router.

**Potential purchase:** require a proposed compressed organ state `T(history)` to support a named conditional-independence/factorization claim before it replaces trajectory history: future decision-relevant evidence must be conditionally independent of discarded history given `T`, under a custodied distribution and axis. This would force the missing distribution/support declaration and prevent a single-trajectory summary from being called sufficient.

Current evidence is too sparse to instantiate the theorem, and the importance-sampling surface lacks the required distribution custody. This is an honest current N/A for computation or promotion; retain it only as a prospective strict gate.

### 4. Functorial databases, Kan extensions, and apparatus migration

**Named consumers:** graph recall #411, lens/bridge retrieval #346, and the quadrality drift apparatus.

A useful bounded target is a typed `QuadralityManifest` with one claim ID, four store projections, content/source hashes, and explicit missing/deferred dispositions. Pullback consistency catches disagreement without guessing. Left/right data migration can describe how claims move when a schema changes, but migration must not manufacture authority: ambiguous or many-to-one migrations require an explicit receipt and otherwise fail closed.

The clean counterfactual baseline is a relational schema with foreign keys and checked migrations. Unless the categorical formulation yields reusable query-preservation laws across several store changes, it remains scaffolding. Do not introduce Kan-extension language into an implementation that is merely a join.

## Required process for future formalism drops

Every future formalism crosswalk should begin with a one-page rent contract, before analogy expansion:

1. Cite the exact theorem/construction and list its hypotheses.
2. Map objects, morphisms, equality/order, and authority surface to concrete local types.
3. Name the cheapest non-categorical baseline.
4. State one expected purchase: theorem, computation, or forced generalization.
5. Name the live consumer and the decision it will change.
6. Pre-register a falsifier and verdict scope.
7. Land either an executable receipt or an explicit formalization/custody blocker.
8. Run the deletion test: if removing the categorical vocabulary leaves the artifact, proof, and tests unchanged, grade the formalism as scaffolding and keep only the output.

No promotion memo should cite a category-theory analogy as authority. A universal-property claim must specify the category and prove the mediating property; an adjunction claim must execute both inequalities/equivalences on the custodied domain; a functoriality claim must check identities/composition or a concrete commuting diagram.
