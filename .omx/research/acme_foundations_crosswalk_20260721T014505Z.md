## Panel-optimality audit

The three classical names solve different problems and cannot be multiplied into a generic “optimal panel budget” claim:

1. **Gap statistic:** estimates a cluster count relative to a specified null reference. Its one-standard-error selection rule is local and conservative; it does not allocate observations or declare coverage complete.
2. **Neyman allocation:** minimizes the variance of one stratified linear estimand under known/estimated stratum sizes and standard deviations (and, in the unequal-cost version, costs). It does not optimize a maximum, an adversarial tail, or several facets at once.
3. **Good–Turing:** estimates unseen species mass from frequency counts. It neither selects cluster count nor supplies an optimal stopping rule without an explicit decision loss and sampling model.

The read-only sibling snapshot of `m1_facet_observer` contains none of these implementations. Its stated contract—one exhaustive `n600` first-checkpoint rank, then a deterministic hardest cohort plus seeded background—already settles finite-population discovery at bootstrap and intentionally violates the exchangeable sampling premise needed for a Good–Turing unseen-mass claim. MAIN should therefore review any later estimator wiring as a new formalization, not as code already present or as ACME-backed authority.

## Numerical recipes worth preserving—and limits

- Prefer Householder QR (with pivoting when rank matters) over classical Gram–Schmidt; use QR solves rather than normal equations.
- Use a direct SVD driver for custody. The manual's educational `A^H A` eigendecomposition is not acceptable for an ill-conditioned rank certificate because it squares conditioning.
- Report `kappa_2=sigma_max/sigma_min` only on the explicitly defined nonzero subspace; the rank-4 head's gauge-null singular value makes the full operator singular by construction.
- For primal-dual solves, record all residual blocks and positivity, not one scalar “KKT residual.” Treat the manual's centering and step constants as pedagogical defaults, not canonical Pact constants.
- Do not lift wavelet threshold values, Monte Carlo sample counts, interpolation degree, or optimizer tolerances as laws. Every such value needs the existing provenance ladder and a typed consumer.
- Never approximate the exact resize operator with polynomial interpolation, even if barycentric evaluation is numerically stable.
