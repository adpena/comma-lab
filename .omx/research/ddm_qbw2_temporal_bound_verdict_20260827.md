# ddm_qbw2 temporal bound verdict — no schema v2; current-GB1 explicit quotient closes at measured scope

## Verdict

**STEP 2 does not fire.**  The smallest gate-eligible full-n600 real-coder result is the
time-ordered joint QBW1 logical stream at **188,860 B**
`[macOS-CPU scorer-free advisory, full n600]`.  That is **103,950 B over** the 84,910-B quotient
allowance and **120,860 B over** the 68,000-B schema-v2 fire bar.  It is 2.224x the allowance and
2.777x the fire bar.

This is a real, exactly decodable, retained coder output, but it is an achievable codelength—not a
Shannon lower bound and not a receiver-closed contest codec.  The negative is therefore
**CURRENT-GB1 / MEASURED-REPRESENTATION scoped**: the measured explicit quotient streams do not fit.
It is not a proof that every possible boundary representation is impossible.

No packet schema v2 was designed or frozen.  No stages 03–05, training, scorer, Metal, Modal, RGB
realization, or exact evaluation ran.  The contest pointer did not move.

## Conditional-leg contract boundary

The pinned GB1 archive is 180,215 B, SHA-256
`ba1f3830cd51b820d7f9b834a1dcc12e8776a0260f9da57a4e8e0944b988e3a4`.  Its receiver exposes a
decoded 12-dimensional pose-carrier basis/coefficient state.  It does **not** carry geometric Pose6;
the older 7.2-KB Pose6 plane is absent.  Substituting GT Pose6, running PoseNet to manufacture it, or
relabeling the 12 carrier coefficients as Pose6 would violate both the charter and NO FAKE.

Consequently the exact QA39 ground-homography leg cannot be instantiated from this GB1 body.  The
runner instead retains a deterministic integer translation derived only from decoded carrier RGB
state, records zero marginal pose bytes, and marks `charter_leg_b_contract_pass=false`.  Its 635,029-B
number is reported for information and excluded from the schema-v2 fire gate.  This is a body-level
incompatibility, not a global negative on pose-conditioned temporal coding.

## STEP-2 outcome and successor routing

Schema v2 is refused because the best eligible real-coder result is 188,860 B, not at most 68,000 B.
Header tuning, another dictionary, or a context coder on the same explicit logical object cannot be
presented as the required representation change.

The arithmetic routes away from serialized exact cracks/masks and toward **QBFLOW's continuous
implicit boundary flow with pose-separated interiors**: decoder computation generates interface
positions, while counted weights/latents carry only a low-dimensional video statistic.  QBMIX still
inherits the oversized explicit alphabet, and QBCERT's preregistered 3-KB-scale saving cannot repair
a 103,950-B allowance miss.  QBFLOW is not admitted by this memo; it merely becomes the named next
family whose mechanism directly escapes the measured explicit-address/object mass.

## Boundaries

- **MEASURED:** real n32 and full-n600 source-derived streams; real three-coder races; exact
  decompression; repeat identity; per-pair rows; HT projection; full-population interface and
  innovation counts; payload, storage, manifest, and resume custody.
- **NOT MEASURED:** QA39 ground-homography prediction on GB1 (required Pose6 absent); any Shannon
  lower bound; receiver-closed schema v2; RGB realization; `R`; SegNet; PoseNet; `d_seg`; `d_pose`;
  `S`; runtime inflate; contest CPU/CUDA evaluation.
- **CLOSED (CURRENT-GB1 / MEASURED REPRESENTATIONS):** exact QBW1 logical sections under a full-time
  context coder, exact Road-mask-plus-exception topology, and decoded-carrier-state translation with
  exact raster innovations.  None can satisfy the 68,000-B fire bar.
- **NOT CLOSED:** a different carried-pose body with genuine decoder-owned geometry; finer or
  canonicalized conditional descriptions not measured here; continuous implicit boundary flow;
  any representation that genuinely changes what is counted.
