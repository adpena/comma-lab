# Rebuild and proof commands

All commands run from `/Users/adpena/Projects/pact`. Bulk stays in `/Volumes/APDataStore/pact/ddm_mrs2/`. The public shell compiles its optional library with `cc -O2 -std=c11 -shared -fPIC`; no compiled binary is a public deliverable. A missing compiler selects Python automatically.

The external runners accept `--resume-from` and bind their inputs before reusing a stage. Use `tools/launch_detached_process.py --output-dir <unique SSD launch directory> --done-receipt <unique receipt name> --env PYTHONDONTWRITEBYTECODE=1 -- <command>` for each heavy command. Do not run the native profile and full public timing simultaneously. A fresh proof directory causes new work; a completed bound directory verifies retained artifacts and reuses completed stages.

1. `.venv/bin/python experiments/ddm_mrs2_profile.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/profile_python` — stratified 48-pair baseline from bound predecessor checkpoints; retains pre-pair states, all replayed tokens and sampled raws.
2. Compile the local test library, then `.venv/bin/python experiments/ddm_mrs2_audit/python_reference_equivalence_test.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/profile_native` — same-state native comparison and exact retained token/raw checks. The executable belongs to the native audit bundle and lives in the review-tracked experiments tree.
3. `.venv/bin/python experiments/ddm_mrs2_bootstrap.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/bootstrap` — offline isolated venv on the explicitly allowed APFS scratch path. Rebuild wheels are retained; original upstream wheel hashes are not claimed for inherited cache repacks.
4. `.venv/bin/python experiments/ddm_mrs2_smoke.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/public_native` — source-identical five-file copy, real public shell, compiler present, explicit CPU, no receiver instrumentation, full cold n600 raw SHA and all 600 pair hashes. Interrupted cold decode restarts its stage; checkpointed setup and completed stages are reused. Raws are removed only after full identity and a deterministic rebuild certificate.
5. `.venv/bin/python experiments/ddm_mrs2_smoke.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/public_fallback --without-compiler` — bare venv with no compiler on PATH, stale-library control, and the 48 real sampled pairs through the Python fallback. This is a 48-pair smoke, not a second cold n600 decode.
6. `.venv/bin/python experiments/ddm_mrs2_bootstrap.py --resume-from /Volumes/APDataStore/pact/ddm_mrs2/bootstrap --cleanup` — certify all installed files and symlinks against retained rebuild inputs before removing the venv. This cleanup is allowed only after both smokes finish.

The public receiver has no research switches, checkpoint code or extra output artifacts. Timing projections are recorded in `TIMING_PROJECTION_PLAN.json`; a projection is never a new T4 leg or authorization. MAIN owns the fresh reader and any later exact measurement.
