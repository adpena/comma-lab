## Paper Formalism Extracted

The paper fixes an environment with a state space and a declarative program language, then restricts attention to a finite implementable vocabulary `v`. Implementable statements form a language `L_v`. A statement's extension `Z_l` is the set of implementable statements compatible with it. Larger extension means weaker hypothesis.

A task is represented as `alpha = (S_alpha, D_alpha, M_alpha)`: situations, correct decisions, and models that exactly separate the correct decisions within those situations. A child task supplies partial evidence; a parent task is a broader task whose situations and correct decisions extend the child.

Induction is model selection from the child-task model set by maximizing a proxy `q_v`. Generalization succeeds when the selected child model is also a model of the parent. The paper compares proxies:

| Proxy | Meaning in the paper | Pact crosswalk |
|---|---|---|
| Weakness | Maximize extension size `|Z_l|`. | Keep the largest scorer-equivalence or tolerance class that still satisfies Seg/Pose/rate feasibility. |
| Description length | Maximize inverse statement length, a minimal-description proxy. | Counted archive bytes remain a separate objective, not the same object as weakness. |

Under the paper's uniform distribution over tasks expressible in `v`, maximizing weakness is necessary and sufficient for maximizing the probability of generalization from child to parent. Minimum description length is neither necessary nor sufficient in that formal setting: the counterexample class can make a shorter statement more specific than a longer but more general statement.

The binary arithmetic experiments instantiate this on addition and multiplication over bit strings. They compare weakest-consistent statements against compressed-MDL statements across small child datasets. The weakest proxy generalizes more often and has larger average extent in the reported tables, with the largest gains at small child set sizes.

The paper's own boundary is important for Pact: the theorem depends on a chosen implementable vocabulary and a uniform task prior over that vocabulary. Apperception-style systems can benefit because their vocabulary and universally quantified formulae make weak hypotheses available. Neural networks are discussed as an open direction where architecture may define the effective vocabulary, not as a proven contest-compression method.

## Pact Crosswalk

Pact is not trying to infer a general arithmetic law from examples. It is trying to ship one byte-closed witness for one frozen video under a fixed scorer and exact archive-size penalty. Therefore:

1. Weakness is a way to choose what not to specify in scorer space.
2. Archive length is still charged by `archive.zip` bytes.
3. Receiver closure decides whether a weak target is real or fake.
4. A weak statement that cannot be realized through uint8/R/parse-back is not a witness.

Operational form:

```text
W* = weakest scorer-sufficient constraint set
C* = shortest legal counted archive whose receiver output satisfies W*
```

This is a naming/citation crosswalk for existing apparatus, not a new canonical equation.
