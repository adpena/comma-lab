## What was NEWLY ENABLED / RECONCILED

### 1. The SPINE was BROKEN in production (the silent-no-op bug — the key fix)

**Finding (NO-FAKE).** `accumulate_tensor_sensitivity` keys the online EMA by
`decoder.named_modules()` **MODULE** names (`blocks.0`, or `decoder.blocks.0` on the FiLM
wrapper) — the SAME keys `apply_score_aware_qat` consumes for the training-time QAT bits.
But the variable-level EXPORT codec checks the **WEIGHT state-dict** keys
(`blocks.0.weight`). These two namespaces are **disjoint** (empirically: 0 overlap on the
base_ch20 decoder, 14/14 tensors). So when `_eval_snapshot` fed the production
`snap.tensor_sensitivity_ema` (module-keyed) into the export codec, `sensitivity.get(
"blocks.0.weight")` MISSED every EMA entry → all-0.0 → rank-normalize → uniform →
fall-back to base 127 levels → **the rate-attack silently no-op'd even when enabled.** The
QAT trained a coarse grid the export never reproduced — the spine was NOT single-source in
production. (The existing R14 tests passed `weight_keys`-keyed sensitivity directly to the
function, which masked the bug at the API level.)

**Fix.** New module-level helper `_sensitivity_for_codec_weight_keys(sensitivity,
weight_keys)` rebinds the module-keyed EMA onto the codec weight keys: for each
`<module>.weight` it resolves the EMA value by trying `<module>.weight` (already
codec-keyed — the test convention), `<module>` (no-FiLM EMA), then `decoder.<module>`
(FiLM-wrapper EMA). Returns `None` when nothing resolves → preserves the codec's own
`None`→uniform→byte-identical default-preserving path exactly (NEVER a fabricated
allocation). Wired at the single codec call site in
`_build_archive_with_optional_sensitivity_variable_levels` (one comment + two lines).

**Now the SAME `||∂S/∂w_t||` tensor drives BOTH the QAT bits AND the export levels** — the
literal single-source spine the bind-all spec calls for. Capacity (taper, offline) + bits
(QAT, online EMA) + levels (codec, online EMA) all follow ONE d_seg-geometry.

  (the +54 B rate cost AND the kit's d_seg/d_pose effect both MEASURED; never a
  bytes-only-without-distortion fake; fails closed on the synthetic scorer).

Default-preserving: both levers off → finished archive byte-identical to the pristine
vendored `build_archive`.
