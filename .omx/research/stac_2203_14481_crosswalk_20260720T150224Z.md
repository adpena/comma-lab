## 1. Exact spatial sensitivity and cached quantization policy

### 1.1 What STAC differentiates

For a DNN loss called `Q` and an input frame `x={x_i}_{i=1}^M`, STAC defines pixel sensitivity

\[
g_{x_i}=\frac{\partial Q}{\partial x_i}.
\]

After RGB-to-YUV and block DCT, it writes the frame's DCT coefficients as
`s={s_i}_{i=1}^M` and differentiates the same loss in that coordinate system,

\[
g_{s_i}=\frac{\partial Q}{\partial s_i},\qquad
\Delta Q = \sum_{i=1}^M g_{x_i}\Delta x_i
         = \sum_{i=1}^M g_{s_i}\Delta s_i. \tag{1}
\]

The paper does **not** name a specific analytic loss such as cross-entropy in Sections II-V; it calls the
object the DNN loss `Q`. For online use without a ground-truth label, it constructs **fake `Q`**: take the
compressed frame's DNN argmax as a pseudo-label, then compute a loss between the output probability vector
and that pseudo-label. That is the loss whose compressed-frame gradient drives Algorithm 1. The paper's
Fig. 4 reports that this fake-loss slope tracks the actual compression-loss slope better than gradients
formed with the raw-frame/actual-label alternatives in its experiment. Any stronger statement about the
loss family would be invented.

### 1.2 First-order loss bound and continuous ideal table

Let `q_{s_i}` be coefficient `i`'s quantization step and use nearest-grid quantization. The paper writes

\[
\Delta s_i=s_i-\operatorname{round}(s_i/q_{s_i})q_{s_i},\qquad
|\Delta s_i|\le q_{s_i}/2.
\]

It therefore upper-bounds the **first-order** loss increment by

\[
\Delta Q_{\max}=\sum_i |g_{s_i}|\,q_{s_i}/2\le B. \tag{2a}
\]

Using `sum_i log2 |s_i/q_{s_i}|` as a file-size proxy, define
`d_{s_i}=|g_{s_i}|q_{s_i}/2`. The paper rewrites its design as

\[
\arg\min_{\mathbf q}\sum_i\log_2\left|\frac{s_i}{q_{s_i}}\right|
\equiv
\arg\max_{\mathbf d}\prod_i d_{s_i}
\quad\text{s.t.}\quad\sum_i d_{s_i}\le B. \tag{2b}
\]

AM-GM gives equal loss-debt slices,

\[
d_{s_i}=B/M,\qquad q_{s_i}^{*}=\frac{2B}{M|g_{s_i}|}. \tag{2c}
\]

This is an analytic reverse-waterfill over a linearized loss and a logarithmic coefficient-rate proxy. It
is not an exact compressed-byte result and is singular when a gradient is zero unless an implementation
adds a clamp; the paper does not specify such a clamp in the stated derivation.

### 1.3 Exact offline `L`-level loss-bound to quant-table cache

Sending one `q_{s_i}` per coefficient would cost roughly one byte per coefficient in the authors' example,
so STAC moves the high-dimensional policy generation offline:

1. On non-test frames at the edge, average `g_{s_i}` by DCT frequency index `n` across blocks to obtain
   `{g_n}_{n=1}^N`, where `N=8x8` for the JPEG block example.
2. Traverse candidate loss bounds `B`. For each, construct one block table
   `T={q_n}_{n=1}^N` with

   \[
   q_n=\frac{2B}{M|g_n|},
   \]

   apply it to frames, and test DNN inference accuracy. Retain the maximum `B` satisfying the required
   accuracy.
3. Configure `L` bounds `{B_l}_{l=1}^L` around that retained `B` and cache

   \[
   T_l=\{q_n^l\}_{n=1}^N,\qquad q_n^l=\frac{2B_l}{M|g_n|}. \tag{offline cache}
   \]

   The paper sets `L=16` only after its configuration study; that number is not part of the derivation.

The tables are DNN-specific but not test-frame-specific. Online messages can then carry small table-level
indices instead of a coefficient-sized vector.

### 1.4 Exact per-region online selection (Algorithm 1)

The current offloaded keyframe is split into equal regions `R_r`; the implementation chooses regions of
3x3 DCT blocks, hence `r_max=ceil(M/(N*3*3))` in the paper's notation. On that compressed keyframe the edge
computes every `g_{s_i}`. For every region and cached level,

\[
\Delta Q^{l}_{\max,R_r}
=\sum_{s_i\in R_r}|g_{s_i}|\,\frac{q^l_{s_i\to n}}{2}, \tag{Algorithm 1}
\]

where `s_i -> n` maps a coefficient to its within-block frequency. It selects

\[
l_{R_r}=\arg\min_{1\le l\le L}
\left|\Delta Q^{l}_{\max,R_r}-\frac{B}{r_{\max}}\right|.
\]

Only `{l_{R_r}}` and the segmentation result are fed back. Lower-gradient regions receive a coarser table;
higher-gradient regions receive a finer table.

The paper's equations (3)-(7) offer a model-specific justification for the equal regional debt constraint:
under a uniform density over the simplex `sum_i d_{s_i}=B`, `d_{s_i}>=0`, it compares the expected product
`E(prod_i d_{s_i})` without versus with the added equal-region constraints
`sum_{s_i in R_r} d_{s_i}=B/r_max` and derives `E1/E2<1`. This is an expectation of the paper's compression
proxy under an assumed density and equal region size. It is not a semantic-accuracy certificate and it is
not evidence that equal regional budgets are optimal for our nonuniform class/edge debts.

## 2. Exact temporal propagation and adaptive keyframe trigger

### 2.1 State and propagation

STAC caches two edge-produced objects on the end device for the most recent keyframe `k_j`:

- `S_{k_j}`: the semantic segmentation result;
- `C_{k_j}`: the spatial compression strategy, i.e. the region-to-quant-table-level assignment.

For every adjacent pair of **raw device frames** `(F_{t-1},F_t)`, it computes dense DIS optical flow
`gamma_{t-1}^t`. It composes those adjacent flows from the last keyframe through time to propagate both the
keyframe image and its segmentation:

\[
(F'_t,S_t)=\operatorname{warp}
\left(F_{k_j},S_{k_j};\gamma_{k_j}^{k_j+1},\ldots,\gamma_{t-1}^{t}\right).
\]

The compression policy is not needed on every non-keyframe. When frame `t` must be offloaded, the previous
keyframe policy `C_{k_{j-1}}` is propagated through the same flow chain to form `C_{k_j}` and is applied to
the new keyframe. If flow leaves a new region without a predecessor, STAC copies the table of the nearest
region. Segmentation pixels without flow similarly borrow the nearest pixel's semantics until refresh.

### 2.2 Trigger (Algorithm 2)

The first frame is uniformly compressed using the middle cached table, offloaded, segmented, and used to
initialize cached `(C_1,S_1)`. For every later frame:

1. compute adjacent raw-frame DIS flow;
2. propagate the last keyframe image and segmentation to obtain `(F'_t,S_t)`;
3. test

   \[
   \operatorname{PSNR}(F'_t,F_t)<\mathrm{THR};
   \]

4. if false, emit the propagated `S_t` and do not offload;
5. if true, force `t` to be a keyframe, flow-propagate the previous `C`, compress/offload `F_t`, run edge
   inference and Algorithm 1, then feed back and replace cached `(C_t,S_t)`.

The paper selects `THR=26 dB` empirically because its Fig. 8 shows a semantic-accuracy knee around 25 dB.
This is a proxy trigger, not a proved error bound: the authors explicitly lack device-side semantic ground
truth, so above-threshold PSNR is an empirically calibrated region where the segmentation drop was small;
below threshold they say accuracy is no longer guaranteed and refresh.

If compression + offload + inference + feedback exceeds a frame interval, the device uses cached
flow-propagated segmentation to meet real-time latency. This is a live-system fallback, not a codec theorem.

## 3. Other exact mechanics

- JPEG prototype: RGB->YUV; separate component-wise 8x8 DCT; table quantization; ZigZag low-to-high;
  Huffman-style entropy coding of runs/small symbols. STAC changes the block tables, not the decoder format.
- Policy metadata: only region-level table indices are fed back and later travel with offloaded keyframes;
  more levels improve granularity but cost more policy bits. Their `L=16` is the empirical balance.
- Region granularity: 3x3 blocks won their empirical sweep; 1x1 carries too much policy metadata and 4x4
  mixes visibly different sensitivities. This is JPEG/transport-specific.
- Feedback closure: the edge recomputes fake-loss gradients and refreshes both `S` and `C` only at forced
  keyframes; the device caches and propagates between them.
