## Adopt Probe Fire Orders

### GDL1-P1 - Phase-coset coder race

Consumer: #920/#149 phase levers.

Status: `QUEUED-WITH-FIRE-ORDER`.

Smallest zero-dollar falsifiable probe:

1. Input: existing GT/candidate masks only, preferably the n600 `lstars` cache or the existing n32 evenly-strided slice used by RL1. Do not use prefix sampling for a population claim.
2. Build four phase residues `(y mod 2, x mod 2)` on the scorer/image lattice.
3. For the selected support family, compare an unconditioned coder against a phase-conditioned coder that stores phase strata plus residual support. Run at least zlib/lzma/Brotli controls with exact decode equality.
4. Report bytes, bytes/flip, denominator, selection mode, and whether any gain survives the cost of the phase tags.

Falsifier: no phase-conditioned representation beats the unconditioned baseline and the relevant W/RL1 control on bytes/flip under decode-equality on a non-prefix n>=32 slice. If falsified, mark formulation-level negative only; do not kill all phase levers.

Why this is new: earlier Weyl work supplied the quotient/gauge language and blind-cell facts. GDL adds the explicit stride-2 subgroup/coset framing that tells #920/#149 to price phase as a coordinate, not as an abstract symmetry claim.

### GDL1-P2 - Per-edge conditional carrier/coder race

Consumer: #984 composition and ty1 synergy rows.

Status: `QUEUED-WITH-FIRE-ORDER`.

Smallest zero-dollar falsifiable probe:

1. Input: existing n600 separatrix geometry plus RL1 interface-price artifacts. No scorer slot required.
2. Build a class-pair graph ledger over boundary cracks with edge IDs, local tangent/normal bins, phase residues, and optional displacement-vs-precision flags from the sx1 split.
3. Race per-edge conditional coders for at least Road<->Lane, Road<->Undrivable, Road<->MyCar, Undrivable<->Movable, and Road<->Movable against a pooled edge-agnostic coder.
4. Require exact decode equality to the described geometry/support, and report bytes/edge, bytes/flip, projected n600 bytes, and what receiver would have to consume.

Falsifier: the edge-conditioned description does not beat the pooled control after edge-ID overhead, or it only wins on a prefix/non-stratified slice. If falsified, kill only this conditional-description formulation; the semantic renderer/HPAC rows remain governed by ty1.

Why this is new: RL1 priced a Road<->Lane description. GDL makes the graph object explicit: the natural unit is an edge message with local invariant coordinates, so #984 should race edge-conditioned carriers instead of a monolithic "seg residual" blob.
