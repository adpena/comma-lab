# TAX2 decodability-tax n=2 — BLOCKED: LTG1 has no same-event exact-conditioned row, and neither fallback supplies one

## Conclusion

**Verdict: `BLOCKED`.** The decodability-tax statement remains an n=1 QX-instance result. TAX2 did
not find a second retained object that exposes the **same immutable event stream** under both a
bit-pinned exact conditioning field and a receiver-generated approximate conditioning field. The
pre-registered positive prediction therefore was **not tested**, the law was neither generalized nor
refuted, and no canonical-equation candidate is admissible from this arm.

LTG1 retains the exact Lane mask, the exact source token field, and five real adaptive-range-coded
rows for each of two event populations. But every retained conditioning variant is receiver-derived;
there is no exact-conditioned row. The `default` and `all_components` populations cannot be used as
the two conditionings because their event symbol counts differ, so that substitution changes `E`.
Using the exact Lane mask itself as a conditioner without a separate causal contract would instead
make the topology event stream target-derived and potentially tautological. Neither operation is the
QX measurement on a second object.

All work was $0 and scorer-free. No scorer, contest evaluator, Metal, MPS, Modal, remote process, or
new coder payload ran. Stage 1 did not fire because Stage 0 failed closed.

## Stage 0 — LTG1 feasibility and arithmetic ceiling

### Same-event check

The default event object is stable across its five retained variants: each has 600 `new_count`,
7,276 `new_kind`, 11,495 `survival`, 11,493 `topology`, and 6,712 `track_ref` symbols. The two rows
nearest the charter's wording are:

| same default event stream | new_count | new_kind | survival | topology | track_ref | payload |
|---|---:|---:|---:|---:|---:|---:|
| unconditioned | 340 B | 679 B | 1,366 B | 1,544 B | 5,346 B | **9,275 B** |
| receiver-derived joint horizon/lifetime/ego/area context | 340 B | 679 B | **1,005 B** | 1,544 B | 5,346 B | **8,914 B** |

The 361 B difference is real and localized entirely to the survival stream, but it is **not the
decodability tax**: neither row is conditioned on `C_exact`. It is a receiver-context gain already
measured by LTG1.

The all-component object is not the second conditioning of the default object. Its trace has 600
`new_count`, 8,268 `new_kind`, 14,645 `survival`, 14,642 `topology`, and 7,450 `track_ref` symbols.
Those differing denominators prove that replacing default with all-components changes `E`.

### Exact-context custody gap

LTG1 does retain:

  `6ca82a7883411d0eb27addac7dcf662e84d2f9cc66404c299da2e15761c0e0cf`;

It does **not** retain or specify a causal map from an exact conditioning field to the same default

the event symbol its own predictor. Coding a coarser function of prior decoded state would be another
receiver-derived row. A valid successor must define the conditioning field and its decode order before
any bytes are generated.

### Ceiling

The best retained receiver-context payload is 8,914 B. With a nonnegative exact-conditioned payload,
the largest possible positive LTG1 tax is therefore **8,914 B**. The finite-coder tax could also be
zero or negative. This interval is too wide to decide the pre-registered sign or fraction, so Stage 1
has no arithmetic authority to fire.
