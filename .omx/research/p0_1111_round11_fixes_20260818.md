## F2(a) — OPEN. I refused to sanitize the shipped receipts, and here is the measurement

My charter directed me to sanitize `GENERATION_RECEIPT.json` and `RECEIVER_PARSEBACK.json`
in place. I checked the premise before editing and it does not hold. **Both files are rows in
the 34-file hashed runtime manifest**, with pinned SHA-256 values that match the on-disk bytes

```

RECEIVER_PARSEBACK.json   manifest pin e79a61baad7d68b4…  15,822 B  match_pin=True
```

I then ran the edit on a **scratchpad copy** (the real packet was never modified) to measure

```

RECEIVER_PARSEBACK.json   after edit 897c8cd710a26370…  11,733 B  match_pin=False

manifest declares                    = 0d0fc008d6a37bd5…
```

**The tree sha does not move.** It is derived from the manifest JSON
(`_runtime_tree_sha_from_manifest`), not from the disk. So sanitizing in place produces the
worst available state: changed bytes shipping under an **unchanged green tree hash**, against
a `[contest-CUDA]` T4 row that evaluated the *original* bytes. That is NO-FAKE #8 — an exact
authority claim for bytes the authority never saw — and it is the precise hazard the census
guard's own docstring already records (*"A green tree sha is not evidence of a clean
directory"*). The round-11 reviewer reached the same conclusion independently: *"The cure is an
adjudication, not an edit."*

So the sanitize is **not a fix an arm can land**; it is a re-stage plus a re-measure. Recorded
old/new shas above so MAIN has the numbers, and the sanitized bytes exist in scratchpad only.

**What I did instead, and why it is the stronger half.** The leak's real defect was never that
the bytes were dirty — it was that **the gate structurally could not see them**, twice over.
That half I fixed (F2(b)). The consequence is that this can no longer be adjudicated by

**Route for MAIN.** The pending keep01 swap re-stages and re-buys everything anyway. Cleaning

## CC-2 — FIXED. Harvests can no longer land where the frontier scan cannot see them

**Charter deviation, stated plainly.** The charter named `tools/fire_modal_auth_eval.py` as the
harvest path. Measured: that tool **dispatches** and arms a poller; the harvest is written by
`tools/modal_harvest_poller.py:138`. A mirror written at fire time would have no result to
mirror. The cure landed in the poller; `fire_modal_auth_eval.py` received only a two-argument
pass-through on the poller invocation — no dispatch or seal logic touched.

**Second deviation, and it decides whether the cure works at all.** The charter specified
`experiments/results/modal_auth_eval_mirror/<label>_anchor.json`.
`tac.frontier_scan.load_experiments_results_anchors` globs
`experiments/results/*/contest_auth_eval*.json` — the filename must carry the
`contest_auth_eval` stem. `<label>_anchor.json` **matches nothing**; the mirror would have been
written faithfully and remained invisible, reproducing the very defect it cures. Filename is
`contest_auth_eval_<label>.json`, and both halves of the glob contract are pinned as module
constants next to the reason.

What the mirror carries (all **copied**, never hand-typed): score, axis, evidence grade, archive
sha + size, both distortions, `n_samples`, hardware substrate, `gpu_t4_match`, `gpu_model_raw`,
lane id, and the source receipt path + its SHA-256. **The score is
`score_recomputed_from_components` and there is deliberately no fallback to `final_score`** —
on the keep01 row those read `0.15716…` and `0.16`, and a fallback is exactly how a rounded
number becomes an anchor. P0 payload custody is unchanged: bytes stay at `--output-dir`; only
scalars are mirrored, so the mirror can never become a competing custody claim.

Refusal path: if the recomputed score, the archive sha, or a derivable canonical hardware token
is missing, **no anchor is written** and a `MIRROR_UNWRITTEN.json` marker records the blocker —
the `POLLER_UNARMED.json` precedent. An anchor with an unmeasured hardware substrate is a false
authority claim, and the scanner would disqualify it silently anyway.

**8 tests, all passing** (`tools/tests/test_modal_harvest_anchor_mirror.py`), including the one
that matters:

```
test_mirror_is_seen_by_frontier_scan — END-TO-END: writes a mirror, then calls the REAL
  load_experiments_results_anchors and asserts one Anchor at 0.1571619225142182,
  axis contest_cuda, substrate linux_x86_64_t4, is_qualifying() True.
```

That test is the anti-orphan control: it proves the cure is wired, not merely built.
