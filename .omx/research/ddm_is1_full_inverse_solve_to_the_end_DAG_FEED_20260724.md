## The 159× confound

The measured `ws1_seglex96` base has 2,845,843 errors. The exact solve has
17,927 errors, so the independently re-derived ratio is
`2,845,843 / 17,927 = 158.7461928934`. The directive’s “159×” is the correct
rounded description; its stated 17,931 error count is not repeated because
the SHA-bound `d_seg × 117,964,800` arithmetic is exactly 17,927 up to decimal
representation noise.

The current evidence does not form one controlled telescoping experiment
across every intermediate representation. The honest stage map is therefore:

```text
L1/L2 grammar or worldsheet prediction
  -> L3 fixed/context-limited RGB paint
  -> camera placement / prototype amplitude
  -> uint8 and frozen R
  -> L4 SegNet features
  -> L5 argmax verdict
```

- v14 proves a low-error exact mask can become high-error after fixed RGB
  projection; that is a formulation-scoped description/paint loss.
- PT1 proves placement and amplitude statistics can recover substantial error
  mass in its own controlled chain; those rates are inherited
  proposal-channel upper bounds, not oracle-diff economics.
- the exact solve survives uint8 and the same real `R`, exonerating
  quantization as the binding family.
- IS1 prices only the exact unstructured L3 residual. The other four
  type/layer cure prices remain `NULL`; inventing a telescoping byte
  allocation would violate Directive 3.

The 2,709,004-error gap between `ws1_seglex96` and the box is therefore a
measured endpoint gap, not a required correction workload and not evidence
against the description family.
