## 1. Quotients and equivalence - the correct object

### 1.1 Newstead's theorem applied at the right type

Let `X` be the ambient frame/witness set, `D subseteq X` the legal/admissible support, and
`U : D -> Y` the frozen evaluator statistic. Define

\[
x\approx_{U,D}y
\quad\Longleftrightarrow\quad
x,y\in D\text{ and }U(x)=U(y).
\tag{1}
\]

**DERIVED-EXACT.** On `X`, (1) is a partial equivalence relation: it is symmetric and transitive,
and `x approx x` holds exactly for `x in D`. Restricted to `D` it is an equivalence relation
`E_(U,D)`. Newstead's kernel-relation exercise and surjection/quotient theorem then give

\[
\bar U:D/E_{U,D}\stackrel{\cong}{\longrightarrow}U(D),
\qquad [x]\longmapsto U(x).
\tag{2}
\]

This is precisely the setoid statement the Weyl arm needed. The maximal exact statistic quotient
does not require a global group action. Group-closure failure is sidestepped at the semantic-rate
level because equality of statistics already partitions the legal support.

For a `D`-valued discrete random witness `W`, (2) gives

\[
\boxed{R^{\rm sem}_{U,D}(0)=H([W]_{E_{U,D}})=H(U(W)).}
\tag{3}
\]

Use `U=T=(A,P)` for the conservative frozen-statistic target or `U=S=(d_seg,d_pose)` for the
coarser exact score-pair target. Equation (3) is an entropy identity, **not** a claim that the
contest receiver can attain it.

### 1.2 Where the groupoid still matters

For a genuine state-dependent groupoid `G => D`, define

\[
xE_Gy\quad\Longleftrightarrow\quad \operatorname{Hom}_G(x,y)\ne\varnothing.
\tag{4}
\]

**DERIVED-EXACT.** Identities, inverses, and composition make `E_G` an equivalence relation. Thus
the quotient “by a groupoid” is its orbit set `D/E_G`, exactly a setoid quotient. The setoid retains
components; the groupoid retains arrow multiplicity, isotropy, stratum/chart data, and constructive
paths. They are complementary, not competing formalisms.

If every arrow preserves `U`, then `E_G subseteq E_(U,D)`. Equality is the missing condition:

> **fiber-complete:** every pair of legal witnesses with equal `U` is connected by a receiver-valid
> groupoid arrow/path.

The thin fiber groupoid `D x_U D => D` is fiber-complete by construction. The named
state-dependent transformation atlas is generally only a constructive subgroupoid (or a generating
relation) and must not inherit that completeness by notation.

If `q_G` is the orbit label, then

\[
\boxed{
H(q_G(W))-H(U(W))
=H(q_G(W)\mid U(W))\ge 0.
}
\tag{5}
\]

**DERIVED-EXACT.** Equation (5) is a clean `constructive_quotient_debt`: a named atlas that connects
only some points in each statistic fiber has a finer quotient and cannot claim the full kernel rate.

If the current object is merely a state-dependent one-step relation `R`, direct quotient notation
is premature. The least valid relation is

\[
E_R=(\Delta_D\cup R\cup R^{-1})^*,
\tag{6}
\]

with all intermediate states constrained to `D`. **NO-GO:** quotienting by raw one-step reachability
when it is nontransitive (`verdict_scope=FORMULATION`). **OPEN:** the generated orbit relation and
its fiber-completeness.

## 2. Infinite descent and well-ordering - certificates, not incantations

### 2.1 General certificate

Newstead's descent argument is over a well-ordered/well-founded carrier. The reusable program theorem
is:

\[
\rho(s_{t+1})\prec\rho(s_t),\quad
\rho:\mathcal S\to(W,\prec),\quad
\prec\text{ well-founded}
\quad\Longrightarrow\quad
\text{no infinite transition sequence}.
\tag{8}
\]

**DERIVED-EXACT.** Strictly decreasing `S` in the reals is not such a certificate: positive reals
have infinite decreasing chains. Strict acceptance on a finite quantized state set bounds accepted
moves, but rejected proposals may still continue forever unless a counter/budget also descends.

Optimality is a second obligation. A finite exhaustive search over `F={x_1,...,x_N}` has ranking
`rho(t)=N-t` and a global certificate consisting of the complete evaluated table plus

\[
\hat x\in F,\qquad S(\hat x)\le S(x)\quad\forall x\in F.
\tag{9}
\]

A greedy certificate instead needs a proved exchange structure. For a matroid independence family,

\[
A,B\in\mathcal I,\ |A|<|B|
\Longrightarrow
\exists b\in B\setminus A:\ A\cup\{b\}\in\mathcal I,
\tag{10}
\]

plus the correct additive-weight objective. No audited real evaluator surface below establishes
(10), M-convex exchange, or an equivalent discrete-convex theorem.

## 3. Enumeration and combinatorics - where exact counts change bytes

### 3.1 L26 is already the constrained enumeration Newstead suggests

The reusable PR101 sidecar grammar dynamically counts, ranks, and unranks bounded canonical Huffman
length vectors satisfying

\[
\ell_i\in[\ell_{min},\ell_{max}],\qquad
\sum_i2^{\ell_{max}-\ell_i}=2^{\ell_{max}}.
\tag{11}
\]

**MEASURED/RE-DERIVED:** the current archived vector belongs to a universe of
`150,553,397,869` valid vectors, so its rank needs 38 bits and the frozen five-byte field suffices.
The current canonical-Huffman stream occupies exactly 1,920 bits. Newstead's counting principles
ground the finite-family logic but do not produce a tighter general encoding than the implemented
exact feasible-family rank.

**NO-GO:** rebuild L26 merely under a new “enumerative” name
(`verdict_scope=FORMULATION`). The real generic opening is self-description: reusable decode still
needs widths/counts supplied out of band; any versioned header must beat that overhead while frozen
PR101 bytes remain untouched.

### 3.2 L31 contains a real coverage distinction

For sorted no-op positions `0 <= p_0 < ... < p_(k-1) < n`, the implemented colex rank is

\[
r=\sum_{i=0}^{k-1}\binom{p_i}{i+1},
\qquad 0\le r<\binom nk.
\tag{12}
\]

For the frozen profile, `n=600`, `k=3`:

\[
\binom{600}{3}=35,820,200>2^{25},
\qquad
\left\lceil\log_2\binom{600}{3}\right\rceil=26\text{ bits}.
\tag{13}
\]

**MEASURED:** the actual positions `[91,428,457]` have rank `15,894,529 < 2^24`, so the existing
three-byte archive is valid. **DERIVED:** that three-byte field does *not* cover the full
three-of-600 family. The encoder fails closed for a higher rank; a source comment asserting universal
coverage is wrong.

**FEED-L31:** distinguish `legacy_observed_rank_24bit` from a generic profile with

\[
w(n,k)=\left\lceil\log_2\binom nk\right\rceil.
\tag{14}
\]

This is a correctness/coverage feed, not permission to mutate validated PR101 bytes.

### 3.3 Conditional constrained-family savings

If event/no-op positions have a receiver-known minimum gap `gamma >= 1`, then

\[
0\le p_1<\cdots<p_k<n,\quad p_{j+1}-p_j\ge\gamma
\quad\Longleftrightarrow\quad
\left|\mathcal F_{n,k,\gamma}\right|
=\binom{n-(\gamma-1)(k-1)}{k}.
\tag{15}
\]

The exact raw-field saving shape is

\[
\Delta B_{raw}=
\left\lceil{\lceil\log_2\binom nk\rceil\over 8}\right\rceil
-
\left\lceil{\lceil\log_2|\mathcal F_{n,k,\gamma}|\rceil\over 8}\right\rceil
-B_{signal}.
\tag{16}
\]

`B_signal=0` only when the constraint is frozen receiver grammar; otherwise its signaling and model
selection bytes must be paid. The contest authority is still
`Delta B_archive = |archive_old|-|archive_new|`, which is `UNKNOWN` until emitted and packed.

For `r` positive run lengths summing to `N`, the universe is `C(N-1,r-1)`. With each run bounded
by `L`, the exact count is

\[
\sum_{j=0}^{\lfloor(N-r)/L\rfloor}
(-1)^j\binom rj\binom{N-jL-1}{r-1}.
\tag{17}
\]

This yields a suffix-count DP rank/unrank grammar. It is a **DERIVED candidate**, not a result from
a current codec. Newstead v0.7 develops fixed-set counts and inclusion-exclusion but does not supply
the bounded-composition/lattice-path codec; that extension is ours and must be labeled accordingly.

The settled HFV7 sidecar already occupies 96 bits for 16 positive deltas. An exact-sum-546
composition also has a 96-bit rank floor before signaling, so there is no universal byte win there.
The sparse Morse-Smale floor `log2 C(N,k)+k log2(K-1)` remains probe-only: current code estimates it
but does not emit rank bytes. Thus constrained enumeration is **FEED-L31/event grammar**, not yet
`WORTH-AN-ARM`.

## 4. Orders and lattices - safe joins versus fake composition

### 4.1 What is genuinely ordered

The duty-to-measure system currently contains different scalar policies: estimated score-headroom
significance, inverse known cost, and absolute costate magnitude. **RE-DERIVED:** these do not define
one canonical objective. #463 is a design-only optimism-per-cost index under conditional linear-bandit
assumptions; nonlinear headroom caps break inherited regret unless reproved.

Let a lever's signed decision features be

\[
v(\ell)=(\text{evidence strength},\ \text{headroom},\ -\text{cost},\ -\text{risk},\ldots).
\tag{18}
\]

Quotient exact ties `ell ~ ell' iff v(ell)=v(ell')`, then order the quotient by coordinatewise
dominance. **DERIVED:** this is a finite Pareto poset. It need not be a lattice: the coordinatewise
meet/join vector may correspond to no real lever. The safe selector returns maximal equivalence
classes and makes any later scalarization explicit/provenanced.

If a lattice is operationally useful, complete the poset to its downsets `Down(P)`:

\[
I\wedge J=I\cap J,
\qquad
I\vee J=I\cup J.
\tag{19}
\]

This is Newstead's powerset meet/intersection and join/union applied to attainable priority ideals,
not an invented lever.

### 4.2 Effects do not compose by lattice join

For a bundle `B`, let `O(B)` be its required proof/measurement obligations. These are syntactic sets,
so a conservative rule may use

\[
O(B_1)\vee O(B_2)=O(B_1)\cup O(B_2),
\qquad
O(B_1)\wedge O(B_2)=O(B_1)\cap O(B_2).
\tag{20}
\]

But if `E(l)` denotes **realized evaluator effects**, generally

\[
E(\ell_1\oplus\ell_2)\ne E(\ell_1)\cup E(\ell_2)
\tag{21}
\]

because overlap, interference, clipping, and nonlinear Seg/Pose coupling create or destroy effects.
The composite is a new measurement node. **NO-GO:** “compose levers = lattice join of effect sets”
(`verdict_scope=FORMULATION`). **FEED-463:** use the Pareto/tie quotient and obligation lattice as
queue infrastructure, while keeping the OFUL/index policy conditional and empirically gated.

The verdict-scope ladder itself is a chain and hence a lattice under `min/max`, but `max` cannot
promote evidence. Two instance failures do not join into a formulation failure; two formulation
failures do not join into a family theorem. Existing escalation proof obligations remain the
authority. Lattice operations may aggregate metadata, never manufacture a stronger negative.

## 5. `F_2`, cycle spaces, and contour coding

### 5.1 Type the geometry before coding it

A class-adjacency graph records which labels touch; it does not by itself encode the spatial curve.
For a pixel cell complex `K`, let a class region be a 2-chain
`r_c in C_2(K;F_2)`. Its boundary is

\[
b_c=\partial_2 r_c\in C_1(K;\mathbb F_2),
\qquad
\partial_1b_c=\partial_1\partial_2r_c=0.
\tag{22}
\]

**DERIVED-EXACT:** this is the actual “region boundaries are cycles” statement. If the codec omits
the known image-frame boundary or allows open junction traces, use relative chains or the affine
`T`-join form below; do not assert (22) on the wrong complex.

For a candidate boundary graph with incidence matrix `B`, `m` edges, `n` vertices, and `kappa`
connected components,

\[
Z_1=\ker_{\mathbb F_2}B,
\qquad
\beta=\dim Z_1=m-n+\kappa.
\tag{23}
\]

A deterministic spanning forest produces a fundamental-cycle basis matrix
`C in F_2^(m x beta)`, and every closed binary boundary has a unique coordinate vector

\[
b=C\alpha,\qquad \alpha\in\mathbb F_2^\beta.
\tag{24}
\]

Against a **dense raw `m`-bit edge-incidence field**, (24) removes `m-beta=n-kappa` raw bits. That
is only a raw linear-algebra shape. A sparse chain/anchor/range code may be far shorter because
`alpha` can be dense.

For an open chain with terminal parity `t=Bb`, choose a receiver-canonical particular `T`-join
`J_t`. Then

\[
\{b:Bb=t\}=J_t+Z_1,
\qquad
b=J_t+C\alpha.
\tag{25}
\]

Fixed/derived `t` costs `beta` uniform raw coordinates; variable `t`, class identities, junction
rotation, and basis/tree selection must also be coded. For `K` exhaustive class masks, the XOR of
their boundary channels is zero in the relative complex (or the known outer-frame boundary in the
absolute complex), so at most `K-1` binary channels are independent. This does not remove the need
to recover class labels.
