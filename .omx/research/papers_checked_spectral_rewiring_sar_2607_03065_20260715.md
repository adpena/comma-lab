## What it says (verbatim-grounded)
LLM-RLVR post-training + model-merging. Problem: dense full-parameter RL updates (a) suppress reasoning (premature test-time-scaling saturation) and (b) cause multi-domain interference on merge. Mechanism = **Subspace-Aligned Rewiring (SAR)**: a POST-HOC weight edit in the base model's SPECTRAL space — "retain this spectral core while removing orthogonal components" of the RL weight-update, keeping reasoning-effective directions + filtering residual directions that degrade/interfere. Results: extracts a reasoning core in ~0.58% of params preserving >99% of post-training performance; improves high-k exploration; 6-of-7 benchmarks on an in-house coding model; better cross-domain merge. No code linked. NO INR / level-set / SDF / wavelet / curvelet / entropy-coding / neural-compression / ego-motion / pose / segmentation content.
