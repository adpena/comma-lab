Dirichlet-multinomial length estimate. R7 closes that seam with materialized frames and exact

- On the historical zero-init T2-final field, a counted mixed pool using Bayesian mode-base plus

  frame.
- On the solve-project long-burn descent point and completed shipping endpoint, the original
  **SMEVR** (Static-Mode Event/Value Renewal) coder is the decisive winner. It splits the modulo-16
  residual into occupancy and circular signed value, conditioning only on the counted base plus

- The portable production default is fixed **SMEVR**. An explicit experimental `auto` option races
  `{SMEVR, Brotli-Q11}` and charges the selected codec tag in the 56-byte header, but is not the
  canonical exporter default because Brotli availability/version is environment-dependent.

The result is a real lossless coder win, but it is not a frontier win. T2, ep389, and the binding

## S4 — honest vehicle entropy floor

The NPZs contain tokens but no realized partition arrays. One realization per checkpoint cannot
identify a nontrivial `H(tokens | realized partition)`. The universal counting lower bound is
therefore exactly **0 bytes**. A Hamming ball around a single observed partition does not improve it.

The receipt also reports unconditional and previous-frame empirical **plug-in** residual entropies.
They are not exact factorial type-class counts and exclude the separately counted mode base.
For orientation only, one explicitly non-authoritative proxy assumes:

1. the empirical first-order residual plug-in distribution is the source ensemble; and
2. the measured pp1 GT-partition KT length `173,616.498 B` upper-bounds realized-partition
   description complexity.

Under those assumptions only,
`H_assumed(R|B,P) >= H_assumed(R|B) - H_assumed(P)`. Subtracting the assumed partition price gives
a proxy average-fiber floor. This is not a theorem, score, or promotion row. The final receipt reports
the checkpoint-specific result:

| checkpoint | counted mode base | residual prev1 plug-in | proxy average-fiber floor | exact universal lower bound |
|---|---:|---:|---:|---:|
| T2 zero-init | 1,536 B | 364,257.557 B | 190,641.059 B | 0 B |
| ep389 solve-project | 1,536 B | 602,234.289 B | 428,617.791 B | 0 B |
| endpoint solve-project | 1,536 B | 605,350.653 B | 431,734.155 B | 0 B |

All three exceed `130 KB` under the proxy assumptions. The exact universal lower bound
remains `0 B`.

## Contingent lossy rung — sensitivity-weighted quant design

**Status: `REALIZED-GATE-OWED`. Not implemented, validated, or admitted by R7.**

S2 measured `nu_max_tolerable_q=0`: no token has certified zero scorer effect. Uniform snapping
increased full-n600 advisory `d_seg` monotonically from `0.0138328552` to `0.0149746280` at 25%
snapped and `0.0230475447` at 80%. Hard-null probes rose from `18.265` mean flips in sensitivity
decile 0 to `87.005` in decile 9. That makes a sensitivity-ranked allocation plausible but forbids
calling any rung free.

The proposed design is:

1. Recompute a fresh scorer-recursive token action price at the exact post-burn endpoint
   `33776302…`. Use the frozen rank-4 head margin/Fisher geometry and corrected
   inner-Jacobian/resize adjoint; never use Euclidean token magnitude as the price.
2. Offer nested token actions `a_i in {keep L16, L8, L4, base}`. For each action measure the actual
   coded byte delta with the R7 winner and predict the first-order score cost.
3. Reverse-waterfill actions in increasing `predicted_delta_S / saved_byte`. For an actually
   measured saving `delta_B`, preregister whole-object break-even
   `delta_S < 25*delta_B/37,545,489`; stop when the marginal action does not pay.
4. Count the complete assignment/selector map unless a separately reviewed receiver proves it can
   derive the same map from already-decoded state. The absent S2 array is not free data.
5. Re-encode the whole candidate, parse it through the actual NumPy receiver, and run a separately
   governed full-n600 realized-through-R scorer gate. Admit only whole-object improvements.

Falsifiers: selector/model bytes erase the gain; deterministic parse-back differs; any assignment
uses uncustodied `|g|`; whole-object realized `delta_S` exceeds the byte-specific break-even; pose
or renderer closure changes; or the exact integrated archive does not shrink. The historical S2
`+0.0002 d_seg` preregistration is not transferred to the post-burn vehicle. A failure kills only
that allocation/formulation, not sensitivity-weighted quant as a family.
