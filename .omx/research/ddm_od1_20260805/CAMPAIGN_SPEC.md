## Answer First

The OD1 route is not "ship the solved seg paint." The route is:

1. Produce the strongest seg base first, even if it spends pose.

4. Run R8/final gates on the final composition, not the transient seg base.

## Ordered Campaign

### Stage 0 - custody and event schedule

Place: `.omx/research/ddm_od1_20260805/` plus SSD run roots under `/Volumes/VertigoDataTier/pact` for any future bulk.

Time: before any scorer, remote, or training dispatch.

Dimension: no candidate bytes generated by this spec; future generated bytes must be archive-contained and hashed.

Why: common contract, no-fake, and P0 reproducibility require deterministic source, checkpoint, and resume custody before score claims.

Gate:

- `PASS` if all source receipts have durable paths and hashes.
- `FAIL_CLOSED` if any evidence is `/tmp` only or if the DSL/compiler cannot express event continuation.

### Stage 1 - seg base production

Place: frame_1 task-space partition, Q4 where needed for solved paint; Q3 only when used as a repair subspace, not the first base.

Time: seg is driven first until TJ1 continuation says extend/stop; no pose gate judges the transient seg-only state.

Dimension: begin with block16/regional phase field or solved-field per-pair basis. Escalate block8/Q4 only where the terminal census and marginal S/byte justify it.

Why: SQ2 proves the seg route is not a solvability wall; the wall is transient pose erosion.

Required outputs:

- Per-pair eta table with denominator and selection mode.
- Stop census: converged, cap-best, pre-plateau, failed.
- Continuation certificate from TJ1-style trajectory bounds.
- Byte-closed archive candidate only if the receiver consumes the seg representation and parse-back is exact.

Pass:

- n>=32 stratified/random gate, not prefix-only, shows retained eta above the ET1 break-even for the priced section and does not rely on cap-best as convergence.

Fail closed:

- n=8 only, prefix-only, no terminal census, or no receiver parse-back.

### Stage 2 - joint pose recovery after the seg base

Place: frame_0 first, because it is seg-blind; otherwise inside-cell AC-only corrections on frame_1. Avoid frame_1 DC paint because canonical recall says constants are PoseNet rowspace, not pose-null.

Time: after Stage 1 creates the conditioned seg base. Pose may spend compute but not erase the already-bought seg field.

Dimension: start with JS1 C-PRIME/k=4 DCT carriage as the first bounded construction; promote only after n>=32 stratified/random survival. If a DirectDescription correction solver is used, it must carry the #888 hinge treatment or a measured alternative.

Why: JS1 shows staged frame_0 repair can preserve seg exactly on sampled rows while reducing pose. Addendum 4 says R8 judges final composition only.

Required outputs:

- d_pose before/after through the actual scorer or frozen-scorer advisory with axis label.
- d_seg invariance or retained eta on the same rows.
- Byte cost of the pose carriage in `archive.zip`, not a free-code claim.
- Per-stage checkpoints and resume state if training/descent is launched.

Pass:

- Pose term increase versus the live bank is <= `0.005` on the gate set, or pose term decreases relative to the seg-only transient while retained eta remains above the Stage 1 bar.

Fail closed:

- Any post-hoc repair that changes frame_1 DC values without AC/null proof; any row that reports proxy pose without round-tripped frames.
