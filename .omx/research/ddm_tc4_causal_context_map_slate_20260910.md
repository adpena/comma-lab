## Causal mechanism and counted boundary

HPAC decodes by `x % 64 + 2*(y % 64)`, not whole-image raster order. Every within-frame map uses the internal sentinel plane populated only after actual symbols are decoded. The encoder's complete-field formulas explicitly mask to the same group availability.

1. **Class row-run:** preceding decoded class × logarithmic run length, reaching 63 preceding cells and resetting at each 64-column block. This extends the old generic seven-cell persistence feature with class identity and longer causal runs.
2. **Vertical transition:** the ordered class pair at the most recent transition strictly above the queried cell, with both endpoints already decoded. Whole-column knowledge is never assumed. The fast receiver tracks completed transitions and queries them with integer bit operations.
3. **Previous pair:** the fully decoded preceding pair's same-cell class × its 3×3 class majority; ties choose the smallest class, and outside-image positions cast no votes. Frame zero uses a sentinel.
4. **Preceding-row predictor bin:** the lane-distance bin saved when the cell directly above was predicted at its own earlier decode event. It does not recompute that earlier prediction using later symbols. Unavailable block-boundary cells use a sentinel.
5. **Horizon × Movable run:** the fixed rows 128–319 indicator crossed with the causal run state for class 3; unavailable left context remains explicit.

Frame-frozen count/expectation ratios provide the added features. All five count banks are deterministically rebuilt from decoded symbols; no fitted per-frame table is shipped. Generic map and integer-algorithm code is free under rule 118; **all 55 fitted weights in the selected rider, its selector and stream are counted**. The map code uses no scorer or GT table at decode. FastContextMixer changes execution cost, not map definitions or coding rows. It resets scratch each frame and inherits the same complete-frame adaptive-state snapshots.

The new TC4 work is the five declared causal map definitions, their online count banks and fast prefix implementation, counted mixer-extension wiring, and retained slate pricing/receiver controls. It reuses the existing TC1/TC3 mixer substrate, RC64 coder, fixed old forty coefficients, and F26 public renderer/correctors. HPAC, semantic and carrier model bytes remain the pinned source objects. No borrowed backbone, fitted scorer, or inherited exact score is claimed as a new TC4 result.
