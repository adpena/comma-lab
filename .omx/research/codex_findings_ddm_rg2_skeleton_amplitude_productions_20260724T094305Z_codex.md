## Finding 1 — RG2 is counted, typed, strict, and additive

RG2 is a version-bumped outer grammar. Its new member is
`production/skeleton_amplitude_coordinates.rg2sa`, tagged
`SKELETON/L3_raster`. L3 is the honest first-acting layer: the generic receiver
derives the semantic mask after RG1 chart correction, applies it at the camera
raster surface, and then hands the result to evaluator-owned exact R. Each
coordinate is addressed by exact pair, ordered class pair,
boundary-or-cell family, temporal class, and one of six receiver-derived
64-row bands. Only signed quanta `-1` and `+1` are legal.

The packet enforces sorted unique addresses, a maximum of 64 coordinates, CRC,
strict member vocabulary, canonical JSON, and decode/re-encode identity. Its
composition order is sealed base → RG1 production/correction → inherited
camera raster → RG2 amplitude mask → exact R. With no amplitude coordinate the
compiler returns the exact input bytes.

pair/bucket, so repeating the same signed coordinate would add no new causal
evidence. Only the 102 newly admissible RG2 signs were run.
