## Adversarial review

### Closed here

- **Missing class types:** all five roles have an executable address family.
- **Lane omission:** execution modifies the inherited V15 Lane chart.
- **Fake sharing:** one physical topology template is actually referenced by
  five role applications and saves 12 raw wire bytes versus direct events.
- **Y0 contamination:** the Y1 receiver explicitly copies only mutated frame 1.
- **Float resize ambiguity:** diagnostics use the existing exact integer R and
  realized uint8 camera output.
- **Custody drift:** operand header binds exact P SHA; product and outer archive
  are strict length/SHA/parse-back objects.
- **Local scalar gates:** none cross the wire.

### Still open and therefore fail-closed

1. The fixture touches pair 0 only. A class-complete *wire* exists; the
   population-global selected n600 operand does not.
2. The 247-byte fixture is not costate-selected and must never enter G83 as an
   empirical state.
3. G89 currently wraps the exact semantic P rather than lowering into the
   compact five-payload PVSA grammar.
4. The conditional Y0-given-Y1 pose enhancement transition is separate G88
   debt.
5. Public `inflate.py`/`inflate.sh`, expected video, runtime custody, and
   full-n600 `upstream/evaluate.py` are not closed.
6. No exact component row exists, so G83 cannot allocate this state and no
   frontier conclusion is possible.
