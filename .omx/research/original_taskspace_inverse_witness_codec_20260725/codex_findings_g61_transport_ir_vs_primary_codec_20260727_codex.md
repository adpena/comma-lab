# G61 — The under-nose mismatch: G49 is a residual transport IR, not the primary codec

## Verdict

The current `PROGRAM_RESIDUAL_LAYERED` name overstates what the executable
contract can represent. G49/G58 are strong custody and realization machinery,
but G49 V1 is structurally a terminal residual transport around a separately
counted V15-derived semantic archive. It is not yet the shortest-program codec
for the selected solution.

This is not a negative verdict on selected-preimage coding. It is a
FORMULATION-scoped blocker on using the closed G49 V1 vocabulary as the primary
archive representation.

## Evidence in the executable contract

1. `SelectedPreimageFactorRoleV1` admits exactly two video-derived roles:
   `ANALYTIC_RESIDUAL` and `LEARNED_IRREDUCIBLE_QUOTIENT`
   (`taskspace_selected_preimage_program_v1.py:119-136`).
2. Their only modes are one Q4 shearlet boundary transport and one opaque
   compact-latent plugin (`:126-130`, `:838-855`). There is no typed topology,
   temporal transition, island birth/death, conditional pose-fiber, entropy
   context, codebook, or joint physical-coding-group operation.
3. Every program is required to carry a `V15SemanticProgramIdentityV1`
   (`:1250-1282`). Its verifier is closed to the V15 solved-template producer
   pair (`:550-555`), requires a V15 solved-template row (`:579-595`), and
   carries `solve_archive`, `v14_archive`, `v14_receipt`, template, and target
   proof dependencies (`:646-659`). Fresh derivation protects originality
   custody, but does not make this a ground-up rate-optimal primary grammar.
4. G49 truthfully remains `research_only=true`,
   `standalone_decode_closed=false`, with outer embedding owed
   (`:1259-1309`).
5. G58 calls the result `PROGRAM_RESIDUAL_LAYERED`, but its production evidence
   proves only a separately counted semantic member plus a G49 packet
   (`taskspace_selected_preimage_operand_adapter_v1.py:1151-1193`).

The G49 memo already listed the missing layered lossy ABI as P0 #9. The new
finding is the macro consequence: a G49-only producer can make G59's schema
green without creating the representation needed to lower the frontier.

## Why this suppresses signal

The intended factorization is:

`shared topology/worldsheet`

`+ temporal transition and sparse support renewal`

`+ Y1 semantic realization and boundary gauge`

`+ conditional Y0 | decoded Y1 pose fiber`

`+ trained irreducible quotient only where analytic structure loses`

G49 V1 can place the first four only in one of two bad homes:

- inside the separately counted V15 semantic archive, where their distinct
  entropy, temporal, and conditional structure is hidden from the whole-object
  allocator; or
- inside the opaque learned plugin, which turns analytically describable signal
  back into “train it” payload.

That is precisely the orphaned/suppressed-signal failure mode. The system has
the right mathematical objects, but the wire type cannot carry them as first
class factors.

The G58 exact two-member archive fix remains correct: it extincted neutral-name
payload laundering. Its side effect is useful pressure—it forces the missing
factorization to be represented inside a typed primary program rather than as
unowned sidecars.

## Required representation inversion

Keep G49 V1 as a strict, reusable terminal residual transport and build a
primary selected-solution program contract with orthogonal logical and physical
axes.

Logical roles:

1. `SEMANTIC_TOPOLOGY_WORLDSHEET`
2. `TEMPORAL_TOPOLOGY_TRANSITION`
3. `BOUNDARY_REALIZATION_GAUGE`
4. `CONDITIONAL_POSE_FIBER_Y0_GIVEN_Y1`
5. `IRREDUCIBLE_QUOTIENT`

Physical coding groups must be many-to-many over logical roles so joint entropy
coding, shared codebooks, population-global transforms, and container overhead
are charged once. A logical factor is not required to own an independent byte
stream, and a byte group may serve multiple logical factors.

The outer representation may still use exactly two members, but their meaning
must become:

1. a typed primary program/grammar with all counted video-specific state; and
2. an optional terminal residual/codebook payload.

It must not mean “immutable V15 semantic archive plus residual patch packet” as
the only candidate shape.

## Nonarbitrary controller

At the corroborated batch-16 low-distortion anchor:

`D = 0.04710898099989964`

and:

`S(B) = D + 25*B/37,545,489`.

Each byte costs `6.658589531221714e-7` score units. Preserving that distortion
allows at most `187,563` bytes to beat `0.172`. A 133,941-byte semantic base
would leave 53,622 bytes, but that is a conditional counterfactual—not a fixed
rate allocation. Replacing the base grammar may change both distortion and
rate, so every group is admitted by the measured same-object differential:

`dS = 100*d(d_seg) + 5/sqrt(10*d_pose)*d(d_pose) + 25/37,545,489*d(bytes)`.

## Executable routing

1. G63 may land the typed producer/resume/custody seam, but it must label G49
   as terminal residual transport and refuse candidate readiness when the
   primary factor vocabulary is absent.
2. The next code unit is a V2 primary program/physical-group ABI, not another
   direct plane codec and not a larger G49 learned blob.
3. Compile analytic topology, transition, boundary, and conditional-pose groups
   from the fresh selected-state teacher; preserve five 120-pair checkpoints.
4. Build the exact outer archive and price every complete object.
5. Train only the remaining score-valued debt after analytic and entropy
   factorization.
6. G58/G59 then reopen the V2 program, exact archive, public inflate, and
   authoritative evaluator chain.

## Falsifiers

- If a G49-only producer can exhibit explicit, receiver-consumed,
  mutation-tested topology, temporal, conditional-pose, and joint physical
  groups without encoding them as the opaque learned plugin, this finding is
  falsified.
- If a V2 primary program cannot beat the complete-object rate/distortion of a
  fresh V15-derived base plus G49 residuals, retain G49 as the winning
  formulation.
- No proxy loss or uncompressed factor size arbitrates the choice; only exact
  outer bytes and realized-through-R component distances do.
