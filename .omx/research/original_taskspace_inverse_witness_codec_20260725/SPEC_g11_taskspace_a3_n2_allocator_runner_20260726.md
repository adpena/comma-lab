# G11 real n2 A3 whole-object allocator runner

Status: L0 research-only executable specification, 2026-07-26. This landing
builds the orchestration needed to measure exact ep725 n2 A3 section variants
through the frozen one-thread macOS CPU scorer. It does not run the real
allocation until the root agent reviews and authorizes the printed exact
command. It cannot establish n600, contest-CPU, contest-CUDA, candidate,
promotion, originality, score, or pointer-movement authority.

## Objective

Compose four already-landed objects without forking their math or wire format:

1. the real causal ep725 n2 `P/G/PASS_P0` construction;
2. the frozen `gt_f0` encoder-only target and scorer custody;
3. G9 `compile_chronological_a3_proposal_groups(...)` over both currently
   executable sparse A interpretations; and
4. G7 `allocate_taskspace_whole_archive(...)`, which alone owns complete
   STORE/DEFLATE rebuilding, dynamic-pointer revalidation, nonlinear score
   arithmetic, and exact accept/reject.

The default experiment coordinate is a bounded geometric row-count ladder
`1,4,16` for each interpretation. The CLI accepts a strictly increasing,
positive comma-separated override. These values are proposal coordinates, not
independent Seg, Pose, or rate thresholds.

## Exact construction and evidence firewall

Encoder setup reopens the pinned constructive spine, the exact n2 target-cache
members, the exact ep725 source directory, and the V14 realization-profile
receipt. It causally decodes the directory-owned counted P with the explicit
runtime, compiles exact target-closing G, derives the predictor-preserving Y1
overlay, and constructs `EncoderOnlyA3TargetV1` from the frozen `gt_f0` slice.
Dense target RGB, labels, poses, scorer outputs, and decoded frames remain
ephemeral and are never serialized into A or into the allocation receipt.

G9 ranks exact integer numerator improvement and compiles finite counted A
packets for:

- `TARGET_CONSTANT_RGB_V1`; and
- `CORRECTED_Y1_SUPPORT_COPY_V1`.

The runner passes only G9's exact A-only transforms to G7. Numerator SSE never
admits a proposal.

## Receiver callback

Every G7 callback strict-parses the supplied outer archive and monolithic
member, then requires its P payload to be byte-identical to the directory-owned
counted P captured during encoder setup. This revalidation happens for every
archive and every replay call.

The initial implementation uses the public monolithic receiver for every
callback. If G10 lands a public typed causal-P receive entrypoint, the runner
may use one cached typed causal surface only when that entrypoint still accepts
the exact archive bytes plus expected outer/member identity and independently
revalidates the archive's P payload against the cached surface. No magic-only,
hash-only, or unchecked cached-P bypass is allowed.

Decoded chronological uint8 frames are held only in a bounded in-memory cache
keyed by exact archive SHA and decoded-array SHA. STORE and DEFLATE must expose
one decoded identity. The measurement callback consumes and evicts only the
entry bound to its exact selected archive/output foreign keys.

## Measurement callback

One measurement session:

- pins Python, NumPy, Torch seed `1234`;
- forces one Torch intra-op and one inter-op thread;
- enables deterministic algorithms;
- loads the frozen `DistortionNet`, PoseNet weights, and SegNet weights once;
- computes and caches frozen n2 target outputs once; and
- forwards every selected decoded proposal twice, requiring bit-identical
  candidate Pose and Seg outputs.

It returns a G7 `TaskspaceRealizedMeasurementReceiptV1` bound to the exact
archive/member/decoded-output/receiver-receipt identities. Component distances
are `[macOS-CPU frozen-scorer advisory]` over n2 only. G7, not this callback,
computes the exact contest equation and dynamic target-relative transition.

## Durable outputs and cleanup

The real command writes two write-once outputs:

1. a canonical research-only JSON allocation receipt containing exact baseline,
   trial, accepted-prefix, and final archive/member/component identities,
   per-section bytes, complete STORE/DEFLATE/selected byte deltas, component
   deltas, exact nonlinear transition fields, G9 acquisition receipts, pointer
   custody, implementation custody, command, runtime, and strict authority
   labels; and
2. the final selected exact archive bytes under a `.not_a_candidate.zip` name.

Both use create-exclusive or equal-byte replay semantics. No dense decoded
frame, scorer tensor, or target tensor is persisted. True scratch lives in
memory and is released after each measurement; there is no bulky rebuildable
spill to clean. A failed run writes neither receipt nor archive. The run is a
bounded deterministic sweep rather than training; completed output bytes are
the resumable terminal stage. An existing equal receipt/archive is a no-op,
while any differing write is refused.

## Receipt truth and blockers

The parser fixes these labels closed: `research_only=true`, `n2_only=true`,
`macos_cpu_advisory=true`, and all n600, contest authority, score, candidate,
promotion, dispatch-readiness, originality, and pointer-movement claims false.
The receipt also records that current proposals are sparse-row controls rather
than a true counted XIP2 receiver mode.

Open blockers after a successful n2 run remain:

- n2 is not n600 evidence and cannot rank or kill the family;
- current A wire has no true counted XIP2 warp mode/domain/pitch ABI;
- same-class G8 realization must be composed separately if not present in the
  frozen baseline;
- standalone runtime packaging and clean inflate are not closed; and
- authoritative exact evaluation requires the governed n600 contest CPU/CUDA
  path on exact candidate bytes.

## Canonical-vs-unique decision per layer

| Layer | Decision | Reason |
|---|---|---|
| causal P/G baseline | adopt canonical | preserves directory-owned P and exact target-closing G custody |
| A acquisition | adopt G9 | one source-binding and packet compiler authority |
| whole-object admission | adopt G7 | dynamic pointer and nonlinear score must not fork |
| semantic receiver | adopt public monolithic/G10 typed seam | real archive consumption is mandatory |
| local scorer session | unique runner-local adapter | scorer must load once and receipts must bind to G7 callback foreign keys |
| durable record | unique closed receipt | allocation dataclasses intentionally have no persistence format |

This is orchestration, not a new codec substrate; the 18-assumption substrate
profile is therefore not applicable.
