# G14 coupled G8 plus conditional-A n2 allocator runner

Status: L0 executable specification, 2026-07-26; `research_only=true`.

Lane: `lane_g14_taskspace_g8_a3_n2_allocator_20260726`.

This is a new runner.  The frozen G11 pre-G8 A3 runner, its tests, and its
receipt schema are historical controls and MUST NOT be edited, copied into a
new name, or treated as this coupled experiment.

## Objective

Measure the first honest atomic composition of the counted same-class
realization coordinate G8 and conditional chronological A on the real ep725 n2
surface.  Every measured treatment is a complete P/G/A archive object:

`exact counted P + source-bound PASS_SEMANTIC_G envelope + conditional A`.

The base envelope is the nonempty, source-bound `PASS_NO_G8_V1` domain.  A G8
treatment replaces it with the corresponding `PASS_THEN_G8_V1` envelope.  A is
then recompiled against that envelope's actual output Y1 through the frozen G10
production API.  An empty or forged G, a legacy pre-G8 A packet, and a G8 packet
paired with A bound to the pre-G8 surface all fail closed.

The exact-target semantic-G P/G/A object remains a separately named chronology
control.  It is not the base for the PASS/G8 acquisition, is never placed in the
same greedy chain, and does not transfer its measured values to the PASS/G8
family.

The runner is n2 `[macOS-CPU frozen-scorer advisory]` only.  It cannot rank or
kill the family at n600, establish an authoritative contest score, emit a
candidate archive, move the frontier pointer, or authorize dispatch.

## Experiment graph

The graph is deliberately conditional rather than three independent scalar
gates:

1. Reopen the exact ep725 counted P, runtime, n2 target cache, scorer weights,
   realization profile, dynamic pointer, and bound stage-ablation receipt.
2. Decode P once into a typed cached causal surface.
3. Compile `PASS_NO_G8_V1`, then compile versioned PASS-A through G10.  Measure
   this exact base object first.
4. Measure the exact-semantic-G chronology control separately.
5. Treat no-G8 as a full conditional-A optimization branch: acquire A on the
   PASS base's own actual Y1, measure its native constant/copy/additional
   programs, and keep those lawful rows eligible for final selection.
6. From the PASS base's actual Y1, run the frozen scorer and construct real G12
   encoder evidence.  Acquire all G12 families and both orders over the
   reviewed prefix set, deduplicating exact program bytes.
7. For each unique G8 program, compile one `PASS_THEN_G8_V1` envelope and then
   compile PASS-A against its post-G8 Y1.  Evaluate that atomic `(G envelope,
   post-G8 A)` transform as a singleton from the same immutable base bundle.
8. Retain every nondominated PASS-A branch and each branch's immediate
   same-series geometric prefix neighbors.  Only this deterministic union may
   enter conditional-A follow-up; scalar PASS-A rank cannot suppress an
   unknown cross-family G8-by-A interaction.
9. Recompute A acquisition on each retained post-G8 Y1.  Evaluate PASS-A first,
   then constant-RGB and corrected-Y1-copy programs at explicit row prefixes.
   Copy rows are ranked on that branch's post-G8 Y1; pre-G8 copy order is
   forbidden in production.
10. For every non-PASS A program, compile the same canonical program against the
   no-G8 source as the matched G0 control and report the interaction

   `I = S(G8,A) - S(G8,PASS) - S(G0,A) + S(G0,PASS)`.

No G8 branch becomes the prefix of another branch.  The G7 allocator may be
called once per singleton, but its ordered greedy output must never be reused
as the baseline for a second G8 proposal.

The matched G0 control for a G8-acquired A program is distinct from the
G0-optimal A acquisition: the former holds program coordinates fixed for the
interaction equation, while the latter reranks on no-G8 Y1 and is the true G0
optimization arm.  Both are lawful measured rows and remain visible; their
checkpoint identities include branch plus program digest so resume cannot
alias controls from different G8 acquisitions.

## Baselines and exact packet domains

The primary baseline is exact P plus G10's nonempty source-bound no-G8 PASS
envelope plus G10's versioned PASS-A.  PASS-A contains zero mutation rows but
is not an empty payload.  It is compiled, parsed, decoded twice, and bound to
the exact P/envelope/Y1 foreign keys.

The exact-semantic-G control uses its own lawful G/A packet domain and is
labelled `EXACT_SEMANTIC_G_CHRONOLOGY_CONTROL_V1`.  It is recorded because the
existing stage ablation shows that semantic topology and realization are not
interchangeable.  It is not called the G0 baseline and cannot seed G12 PASS-base
evidence.  It is diagnostic and explicitly excluded from selection of the
production PASS/G8 research row even if its numerical score is lower.

Every production PASS/G8 A program, including zero-row PASS-A, is a canonical
`PredictorPreservingA3ProgramV1` compiled only by the frozen G10 conditional-A
API.  Direct packet construction and the legacy `TACA3P1` compiler are
forbidden on this branch.

## Real G12 evidence and custody

The G12 evidence is constructed only inside the reviewed real run from:

- `Z`: the decoded PASS/predictor semantic labels;
- `T`: the exact frozen n2 `lstars` slice;
- `H`: actual frozen SegNet argmax labels from the receiver-closed PASS-base
  Y1;
- candidate and target scorer-plane RGB derived through the exact frozen
  camera-to-scorer resize operator.

The exact integer resize numerator and its common denominator are custody
authority.  The uint8 RGB coordinate consumed by G12 is the deterministic
nearest-byte projection `(numerator + denominator//2)//denominator`; the
receipt records numerator hashes, denominator, projected-byte hashes, source
camera hashes, and the fact that the projection is an encoder coordinate rather
than a scorer-output or admission claim.  Dense arrays remain ephemeral.

The canonical four-way `(Z,T,H)` partition is always recorded with mask hashes,
global counts, and per-target-class counts:

- closed: `Z=T and H=T`;
- realization debt: `Z=T and H!=T`;
- topology debt: `Z!=T and H!=T`;
- fortunate semantic mismatch: `Z!=T and H=T`.

The four counts must sum to `pair_count*384*512`; all class-count vectors must
close.  G12 programs may select only realization-debt cells.

## G8 acquisition and screening

All frozen G12 families are present:

- class-shared target medoid;
- every explicitly configured bounded target-medoid palette; and
- target-pixel RGB oracle control.

Both canonical-address and target-RGB-SSE-descending orders are present.  The
full reviewed prefix universe is exactly
`{1,4,16,64,256,1024,4096,debt_count}`, clipped to positive unique values no
larger than the actual debt.  The cheap default is `{1,4,16,64,debt_count}`.
The CLI can select only `cheap`, `full`, or an explicit sorted subset of the
full universe; arbitrary threshold values fail closed.  The complete debt
endpoint is always retained.

Acquisition receipts remain complete, but scorer work uses G12's
`unique_program_proposals`.  A second runner-level digest deduplication is
required after prefix filtering, so aliases cannot spend duplicate branch
rows.

Each G8 branch is first measured with PASS-A.  Nondominance is computed over
the exact tuple `(d_seg, d_pose, selected_archive_bytes)` with no scalar
component threshold.  Every nondominated row and its immediate smaller/larger
geometric neighbors within the same family/order/palette series are retained.
Retention is scheduling, not admission or a family verdict; a lower-ranked
nondominated family remains live because conditional A may reverse its rank.

## Conditional A follow-up

The explicit A prefix universe is `{0,1,4,16,64}` clipped to available positive
rows.  Zero means the versioned PASS-A program and is always measured first.

Constant-RGB acquisition uses the frozen target-Y0 scorer coordinate.  Copy
acquisition is recreated per retained G8 branch from its actual post-G8 Y1 and
the exact target Y0.  Rankings use exact integer resize-numerator SSE only to
order rows; they never admit a treatment.  Rows are canonicalized into
`PredictorPreservingA3ProgramV1`, then compiled through G10.  Reusing G9's
pre-G8 copy ordering is an implementation error.

The orchestration core also exposes one typed, append-only additional-A
provider seam.  A later frozen counted `COPY_CONDITIONAL_Y1_V1` global action
and counted XIP2 actions may enter there without changing singleton scheduling,
matched G0 interaction controls, checkpointing, or invariant enforcement.
Global copy is an empty-body receiver action (`Y0 := post-G8 Y1`), not 196,608
sparse copy rows; the runner must never emulate it with the sparse grammar.
Extension implementation/config custody is registered as a distinct durable
contract so an existing PASS/G8 screen can resume and add the new A family
without rewriting its core manifest or completed rows.

For all A variants sharing one G8 envelope, the receiver must prove identical:

- final Y1 bytes and per-frame hashes;
- candidate Seg argmax bytes and hash; and
- `d_seg` exactly.

Only Y0/Pose and rate may vary.  Any violation aborts the run rather than
silently suppressing chronology signal.

## Whole-object arithmetic

Every row builds both canonical STORE and DEFLATE archives, strict-parses both,
double-decodes through the G10 cached causal-P receiver, and prices the selected
smaller exact archive.  Report raw section, monolithic member, STORE, DEFLATE,
and selected ZIP bytes and deltas separately.

The only admission arithmetic is

`delta_S = 100*delta_d_seg + sqrt(10*d_pose_after) - sqrt(10*d_pose_before) + 25*delta_B/37_545_489`.

For a negative distortion-only delta, the exact finite byte ceiling is

`delta_B_max = -(37_545_489/25) * distortion_delta`.

The receipt records the real-valued ceiling and the greatest admissible integer
byte delta under strict `delta_S < 0`.  There are no arbitrary Seg, Pose, rate,
or interaction thresholds.  G7/dynamic-frontier canonical arithmetic is
reused, not reimplemented as an independent score law.

## Receiver and scorer sessions

The exact ep725 causal P surface is decoded once.  Every STORE/DEFLATE callback
passes the complete archive plus expected outer/member identities to G10's
cached-causal receiver.  That API must strict-parse each archive and revalidate
its archive-owned P bytes against the cached surface.  Hash-only, magic-only,
or unchecked cache hits are forbidden.

One frozen CPU `DistortionNet` instance is loaded per process.  Python, NumPy,
and Torch share seed `1234`; Torch uses one intra-op and one inter-op thread and
deterministic algorithms.  Target outputs are computed once.  Every candidate
forward runs twice and must be bit-identical for Pose and Seg outputs.  The
measurement receipt is bound to the exact archive, member, receiver receipt,
decoded-output hash, scorer custody, and target-forward custody.

Every whole-object row also persists a bounded dense-free scorer-evidence
object: measurement-receipt hash, candidate-forward hash, Pose6 hash, the two
exact per-pair Seg/Pose distances, `sample_count=2`, frozen-scorer hash, and
target-forward hash.  Aggregate d_seg/d_pose must equal the exact float32 mean
of those pair values on construction and parse-back.  Frames, RGB arrays,
logits, labels, and poses themselves remain ephemeral.

Decoded camera frames, resized RGB, masks, logits, poses, and labels are
bounded in memory and evicted after their exact measurement consumer.  They are
never written to the run directory.

## Resumability, storage, and no-launch boundary

The CLI defaults to refusal.  `--execute-reviewed` is mandatory for any real
source decode or scorer load.  `--print-reviewed-command` prints the locked
command without entering the real path.  This landing MUST NOT run that
command; root review and explicit authorization are owed.

A real run requires a durable non-`/tmp` run directory.  Initial launch writes
an atomic manifest binding configuration, implementation hashes, input custody,
seed/thread settings, and the exact dynamic-pointer start snapshot.  The
implementation manifest covers the bounded behavior-critical real-path closure,
including score geometry, exact resize, outer ZIP codec, overlay, receiver
parse/dispatch dependencies, G10/G12, materializer/measurement tools, upstream
scorer module, and frame conversion.  The runtime manifest binds Python,
NumPy, Torch/scorer dependency distributions, platform, and zlib compile/runtime
versions without importing Torch during reviewed-command printing.
`--resume-from` reopens that directory and refuses if configuration,
implementation, input custody, or the stored start-snapshot bytes/hash are
internally inconsistent.  A newer live pointer does **not** invalidate
pointer-independent component measurements or pairwise `delta_S`: resume
preserves the immutable start row and appends a verified current snapshot for
reporting instead of rewriting history.

Each completed stage and each measured branch is preserved as a distinct
atomic JSON checkpoint (`tmp + fsync + no-replace link + directory fsync`).  Checkpoints
are write-once/equal and include enough exact foreign keys to deterministically
rebuild and verify the branch.  The process checkpoints immediately after each
branch, so a crash loses at most the currently executing branch.  Resume skips
only byte-closed, parse-backed checkpoints whose custody still matches.

The final canonical receipt is write-once.  The selected research archive is
written as `.not_a_candidate.zip`; no file named `archive.zip` is emitted.  No
dense frame or scorer tensor persists.  Small manifests/archives may remain
local; any future large expansion must use the repository storage-waterfall and
certify-or-block cleanup path before launch.

The dynamic pointer is verified at start and immediately before final receipt
publication.  Pairwise score transitions use the exact three-axis equation and
are independent of the target pointer.  Target-relative sublevel comparison is
**not admissible here**: these n2 research ZIPs contain only the counted
`0.bin` member and omit standalone contest runtime/inflate closure.  Final
reporting records the latest pointer only as a non-comparable research
lower-bound diagnostic and emits no `below_target`, `gap_to_target`, or sublevel
admission field.  It does not retroactively mutate branch measurements.  The
active score is never hardcoded.
