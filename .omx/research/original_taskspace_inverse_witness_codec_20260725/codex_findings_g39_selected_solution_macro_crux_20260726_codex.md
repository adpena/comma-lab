receiver-executable interior of the existing G17 selected-solution compiler.
Do not add another parallel compiler or controller.

The exact immediate cut is:

> Fresh current-G17 encoder-only obligations -> typed counted operands for the
> already-existing semantic-G, realization/G8, conditional-A3, and R10 receiver
> operations -> actual chronological `uint8` pair population.

The hidden gem is that most physical operations already exist:

- `generative_taskspace_correction.py` has a legal finite semantic-G grammar;
- `taskspace_monolithic_pga_receiver.py` actually composes ep725 P, semantic G,
  predictor-preserving realization, and conditional A into chronological pairs,

  operands and changes `uint8` frames, and supports 1..600 pairs;
- `taskspace_public_auth_eval_closure.py` gives G29 a real full-n600 public
  `LVPG2 -> LVLS1 -> raw` inverse/custody surface, but only for the current
  ep725 state;
- G17, G33, G36, and G38 already provide lifecycle, whole-object, endpoint,
  selection, and proof-byte vocabulary.

What does **not** exist is the typed executable foreign key that says which
fresh teacher obligation becomes which counted operand, which existing receiver
operation consumes it, which population coordinates it owns, and which actual
output bytes result. G17's current VM can move bytes (`CONCAT`, `SLICE`, `XOR`,
`REPEAT`, `EMIT_SECTION`) but has no topology, raster, feature-relay, or
multiple-shooting physics. Its R10 consumer and exact contest adapter therefore
correctly fail closed.

That missing map is upstream of strict receipt work. A perfect receipt for the
current state cannot create a better state.

## Option adjudication

### 1. Strict whole-object receipt — necessary, not selected

G17 lifecycle types, G33 whole-object endpoints, G36 readiness, and G38
proof-byte certificates already cover the important authority shape. G40 has
also closed G33's consumption of G38 proof bytes. More receipt work before a
candidate-generating action exists improves certainty about an empty action
universe. It is downstream apparatus, not the representation bridge.

### 2. A bare typed G17 -> G29 adapter — necessary, but wrong as the next macro cut

G29's current ABI consumes LVPG2 and exactly reconstructs the ep725 LVLS1
state. A field adapter cannot send semantic factors to a parser that expects
that state, and cannot silently call an ep725 state inverse a task-space raster
compiler. The G17/G29 raster receipt should follow the new actuator IR and bind
its actual public output. If implemented first, it should be labeled a closure
adapter for the existing high-distortion control only.

### 3. A new parallel factorized compiler — rejected

The repository already has the semantic roles, seven scientific factors,
physical G/A/R10 operations, G17 definition owner, G19 costates, G33 controller,
and G38 certificates. A second ontology/compiler would recreate the exact
signal-orphaning failure G24 warned against.

### 4. Semantic/pose teacher-to-actuator IR inside G17 — selected

This is the smallest cut that can create a different complete state while
reusing the existing physical receiver work. It converts fresh encoder-only
information into legal counted sufficient statistics and proves their actual
receiver consumers. Costates can then rank real actions, G29 can expose their
public output, and G33 can select among complete endpoints.
