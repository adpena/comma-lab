# G3 dynamic level-set inverse candidate specification

## Objective

Build the first complete original `P + G + A [+ T]` archive around the best
already-byte-closed task-space level-set seed, then admit every change only by
the exact coupled contest score against the live canonical frontier pointer.

This supersedes the architectural assumption that `P` must be V9-only and the
older practice of assigning independent fixed ceilings to Seg, Pose, or rate.
V9/V10 remain source mechanisms and inverse-geometry libraries; the selected
predictor instance is determined by measured same-object rate/distortion.

## Dynamic admission law

At every candidate transition, refresh
`.omx/state/canonical_frontier_pointer.json` and compute

`S = 100*d_seg + sqrt(10*d_pose) + 25*B/37_545_489`.

For candidate state `x` and proposed change `delta`, admit only if the exact
realized-through-R same-archive value

`DeltaS = 100*Delta(d_seg) + sqrt(10*(d_pose + Delta(d_pose)))
          - sqrt(10*d_pose) + 25*DeltaB/37_545_489`

is negative.  Crossing authority requires `S(x + delta)` to be strictly less
than the live pointer.  No independently fixed Seg, Pose, payload, coefficient,
or per-pair threshold is an admission rule.  Derived byte ceilings are
recomputed from the other two measured components for the exact same object.
The executable authority is `tac.score_geometry.score_sublevel_audit` plus
`score_transition_audit`; do not fork or hand-roll a second threshold surface.

## Executable composition

1. Reopen and hash the ep725 archive and shipped decoder; decode a bounded pair
   set twice and bind exact chronological raw identities.
2. Wrap that receiver as a typed `P` source that exposes decoded frame1 bytes
   and decoder-owned semantic identities without placing SegNet, PoseNet, or a
   target label table in the decoder.
3. Generalize the predictor/G seam without false state: static/local G families
   may consume labels alone; topology/worldsheet families must consume an
   explicitly typed counted transport coordinate.  Reuse the existing
   pose-trajectory/XIP2 coding mechanisms where profitable, but label this as a
   transport statistic—not evidence that PoseNet distortion is solved.
4. Compile a counted `G` correction against that typed `P` state; strict
   parse/apply must change emitted frame1 bytes and preserve a matched G-only
   counterfactual.  Until the generalized seam exists, G2 is a V9-specific
   causal proof and ep725 compatibility remains fail-closed.
5. Verify the corrected `Y1` bytes, then decode counted `A` to materialize
   `Y0 | Y1`; an A-only counterfactual changes Y0 and preserves Y1.
6. Emit one monolithic counted payload and a standalone generic runtime.  All
   learned/video-derived base, correction, preimage, optional-terminal,
   selector, table, and container bytes count.  Generic deterministic receiver
   code is free under rule 118, but it must pass a data-in-code audit: any
   video-derived constant embedded in runtime source is payload and therefore
   forbidden unless moved into the counted member.
7. Treat the outer archive coder as a measured coordinate, not a frozen
   structural choice.  G2 uses `ZIP_STORED` only to make the first G/A causal
   proof maximally transparent; it is not the G3 rate format.  The frozen ep725
   wrapper already demonstrates why: its 84,536-byte LVLS1 member occupies an
   83,838-byte DEFLATE archive.  For every complete P/G/A[/T] member, build and
   parse back preregistered deterministic STORE and DEFLATE encodings (plus any
   already-reviewed inner entropy modes), then retain the smallest exact valid
   archive.  Price the recompressed monolithic archive itself; never add the old
   source-ZIP bytes to separately compressed section estimates or require the
   archive to be larger than its uncompressed member.
8. Measure exact section bytes and exact local realized component deltas.
   Reverse-waterfill across G/A coordinates by `DeltaS`, remeasuring after every
   admitted finite change because Pose's square-root marginal is state-dependent.
9. Use the existing quantization-aware/curvelet machinery only for the residual
   coordinates that remain profitable after analytic/inverse construction.

## Staged acceptance

### Bounded structural gate

- n2 then preregistered n24 only; no promotion inference.
- clean-root deterministic double decode and byte-identical repeat output;
- strict one-member parse-back with no uncounted sidecars;
- receiver-source audit proves that the free generic runtime embeds no learned,
  source-derived, pair-indexed, target-derived, or scorer-derived data;
- G mutation changes Y1; A mutation changes Y0; both isolate non-target bytes;
- source and payload lineage closed for every counted byte;
- actual archive byte delta and exact local `DeltaS` recorded.

At the frozen 83,838-byte base, recompute the currently permitted conditional
`d_seg` coordinate with `score_sublevel_audit` from the freshly refreshed
pointer and the measured pose coordinate.  Do not persist a leaderboard
snapshot as an acceptance value.  The n24 ep725 `d_seg ~= 0.00345548`
identifies a large G debt relative to the last measured sublevel surface; it
does not make the seed a candidate, and its exact admissible margin must be
re-derived whenever the pointer or either other score coordinate changes.

### Full n600 gate

- governed launcher, live storage/memory preflight, resumable stage checkpoints,
  and success-only certified scratch cleanup;
- same complete archive measured through the exact realized receiver;
- dynamic pointer refreshed immediately before admission;
- standalone clean-root double inflate within the contest time budget;
- exact contest-CPU and contest-CUDA replay on identical archive bytes before a
  score or frontier claim.

## Explicitly excluded

- HNeRV, PR130, or any public archive/checkpoint/latent/selector/payload bytes;
- carrying the ep725 checkpoint as an uncounted runtime dependency;
- treating the old `d_pose <= 0.00161` or `pose payload <= 7195 bytes` probe
  ceilings as current acceptance criteria;
- using dense C1 planes, target labels, target Pose6, or scorer outputs as
  decoder data;
- training a residual family before the analytic and counted inverse coordinates
  have an exact nonnegative marginal-price receipt.
