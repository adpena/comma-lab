## Outcome

G63 closes the smallest real unit that was absent after G58/G59: a typed
producer config and resumable runner that can consume a fresh own-lineage G49
packet, publish the G58 identity/five-stage terminal chain/two-member outer
proof, and feed those exact artifacts into G59.

It does **not** make G49 the primary task-space codec. G49 V1 is truth-labelled
`G49_TERMINAL_RESIDUAL_TRANSPORT_V1`. Its closed vocabulary is only:

- `SHEARLET_BOUNDARY_TRANSPORT_Q4`;
- `COMPACT_LATENT_QUOTIENT_PLUGIN`.

The generic decoder algorithms are free code. Every video-derived analytic
atom, learned latent, and learned parameter is counted in the G49 packet under
`COUNTED_ANALYTIC_OPERAND` or `COUNTED_LEARNED_OPERAND`. Analytic does not mean
free: only the generic analytic rasterizer is free.

## Primary-codec boundary

The following primary layers remain unexpressible in G49 V1, but already have
canonical ownership and scientific-role types in the G17 selected-solution
compiler:

1. shared topology/worldsheet state;
2. temporal transitions and island birth/death;
3. conditional `Y0 | decoded Y1` pose enhancement;
4. entropy contexts;
5. joint physical coding groups.

Therefore every V1 config carries:

```text
primary_program_codec.status = OWED_G17_VERTICAL_LINKER
primary_program_codec.candidate_ready = false
```

G59 accepts and recursively validates the producer **schema/custody join**, but
must return both exact candidate blockers:

```text
G17_PRIMARY_ARCHIVE_PRODUCER_OWED
G17_PUBLIC_RECEIVER_OPERATION_REGISTRY_OWED
```

A syntactically valid G49-only config never obtains `candidate_admission=true`.
Malformed, mutated, cross-campaign, source-drifted, or G58-mismatched configs
refuse earlier as `PROGRAM_PRODUCER_CONFIG_REFUSED:<reason>`.

This is deliberately not a request for a V2 schema. The canonical
`taskspace_selected_solution_compiler.py` already owns topology, connection,
gauge, pose-fiber, quotient, entropy-context, and many-to-many physical-group
semantics. The missing product is the executable vertical linker from selected
state into those owners/groups and then through the public receiver.

## Config contract

Schema: `tac.taskspace_program_residual_producer_config.v1`.

Production is exactly:

- 600 chronological non-overlapping pairs;
- five immutable stages of 120 pairs;
- frozen scorer batch size 16;
- one fresh G49 packet and the exact fresh semantic archive it names;
- exact semantic compile receipt, target-custody receipt, G51 auxiliary
  aggregate, compiler source, generic V10 source, and G59 campaign seal;
- an exact factor inventory derived from G49 parse-back;
- exact learned-decoder source rows for every learned section and no others;
- one output root on the SSD waterfall;
- two outer ZIP members only: semantic archive plus G49 packet.

The checked-in
`../configs/taskspace_program_residual_n600_example_20260726.json` is
deliberately `execution_ready=false`. It contains no invented packet, selected
state, factor, hash, or output receipt. The runner refuses it until a fresh G49
producer supplies exact file identities and factor rows.

## Descriptor-stable and no-hidden-payload rules

Every source/config/checkpoint read uses one `O_NOFOLLOW` descriptor and compares
pre-read `fstat`, post-read `fstat`, and no-follow named `stat`. Symlinks,
replacement, truncation, growth, non-regular files, and hash/byte drift fail
closed.

The counted outer archive is deterministically rebuilt and then independently
reopened by G58. Its complete member set is exactly the semantic archive and
G49 packet. Member names that imply target, label, pose, scorer, raw, source,
Y0, or Y1 payloads are forbidden. No decoded plane, direct source plane, raw
label, pose array, scorer artifact, or historical payload is persisted by G63.

## Resumability

The CLI requires:

```bash
tools/run_taskspace_program_residual_n600.py \
  --config /absolute/path/config.json \
  --resume-from /Volumes/VertigoDataTier/pact/<run-id>
```

`--resume-from` must equal the typed `output_root`. Each stage writes a distinct,
atomic, write-once `stage_XX.json` checkpoint. A stage receipt binds the exact
config, packet, pair range, G58 admission, output hashes, and predecessor chain.
It stores no raw arrays. On resume, preserved stages are descriptor-stably
reopened and their chain is verified; G49 decoding begins directly at the first
missing 120-pair segment. Prior completed segments are not decoded again.

The stage checkpoint is byte-close-loadable because all necessary state is the
immutable G49 packet, bound semantic/decoder/auxiliary custody, predecessor
chain, and typed config. Failed or incomplete bytes are never silently deleted.
