# DDM M3 solve/descend frontier equations

These equations stabilize the accounting rule, not the missing measurements. They are not
registered as a canonical empirical law.

## 1. Sequential reachable-set accounting

Let `A_0` be the exact v15 control artifact and let one byte-custodied chain be

`A_0 -> A_solve -> A_correct -> A_separate`.

For exact global Seg error count `E(A)`, the telescoping gains are

`G_solve = E(A_0) - E(A_solve)`,

`G_correct|solve = E(A_solve) - E(A_correct)`,

`G_separate|solve,correct = E(A_correct) - E(A_separate)`.

Only this sequential chain authorizes addition:

`E(A_0) - E(A_separate) = G_solve + G_correct|solve + G_separate|solve,correct`.

An independently measured v19b gain from `A_0` is not `G_correct|solve`. This prevents the
pre-synergy single-move partition from being silently reused after the base artifact changes.

## 2. True #366 scope and over-scope percentage

Let `T=136,839` be the maximum integer error count and let the precursor composition include the
registered role solve, full-stratum inverse solve, correction saturation, and conditional frame
split. Then

`N_366 = max(0, E(A_separate) - T)`.

For c1's assigned `N_c1=2,377,273`, the requested over-scope percentage is

`X = 100 * (N_c1 - N_366) / N_c1`.

`X` is undefined until `E(A_separate)` is measured or bounded by a valid infeasibility
certificate. Current custody yields only

`X_evidence = 100 * 73,945 / 2,377,273 = 3.110496775%`,

where 73,945 is the v19b residual-bucket gain from `A_0`. `X_evidence` is evidence that the old
partition is stale; it is not `X`. The current certified interval is

`0 <= N_366 <= 2,377,273`.

## 3. Per-class signed correction

For class `c`, with class-target sites `n_c`,

`g_c = E_c(A_before) - E_c(A_after)`,

`Delta D_c = -g_c / n_c`.

Positive `g_c` is net closure and negative `g_c` is net harm. Since the v19b program is one
shared 3,884-byte home, no class byte price exists without an additional ownership rule and
measurement.

## 4. Nonadditive interaction

For score gain `g(U)=S(empty)-S(U)` of decoded move set `U`, the pair interaction is

`mu(i,j) = g({i,j}) - g({i}) - g({j})`.

V19b's positive amplification falsifies the additive approximation. A solve/correction
composition therefore requires exact replay, not singleton summation.

## 5. Exact frame incidence

The frozen scorer gives

`D_seg(I_0,I_1) = D_seg(I_1)`,

so

`partial D_seg / partial theta_0 = 0`

for any frame-0-only variable that leaves frame 1 byte-identical. Pose remains

`D_pose(I_0,I_1)`,

because official PoseNet consumes YUV6 from both frames. Thus each frame-0 class row has zero Seg
residual, while the conditional Pose rate

`R_0(tau | I_1,xi) = min L(theta_0) : D_pose <= tau, I_1'=I_1`

remains unmeasured on the current DDM vehicle. R1 supplies only the quarantined comparator
`tau=0.001610`, `L=7,195 B`.

## 6. Certificate condition

Absence of an admitted proposal is not infeasibility. A nonzero
`certified_infeasible_residual` requires a named reachable set, exact byte box, exhaustive or
mathematically complete search/certificate, real receiver replay, frozen scorer output, and a
scoped verdict. G2G2's six-pair finite search and G2's scorer-free atlas do not satisfy that
condition for any full n600 class stratum.
