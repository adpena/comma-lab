## 1. Why thin ⇒ low-dimensional (the medial-axis count)
A lane marking is a tubular neighborhood of a centerline curve γ: M = T(γ, w), w≈const small. The medial-axis
transform reduces |M| pixels to a centerline (~|M|/w points) + width. A dashed segment ≈ a short B-spline
(~3–4 control points = 6–8 numbers). The "long thin tail" is exactly the regime where the **boundary length ≫
enclosed area** → the medial axis is a near-lossless dimension collapse (a blob, area≈length², does NOT
collapse — the operator's "blob may not compress well").

## 2. Codec A — parametric WORLD-LANE + ego-homography (ultra-compact; the temporal amortization)
Lane markings are STATIC in the world. Across 600 frames they are ONE set of road-plane curves Γ + the ego
trajectory. Under the **ground-plane homography** `H_t = K·[r₁ r₂ t]_t` (known camera intrinsics K + ego
pose), `γ_j^t = H_t(Γ_j)`. Store Γ (world lanes) ONCE + ego pose (already stored for d_pose) → project.
- **Storage:** Γ ≈ 4–6 lines × ~15 control pts × 2 + dash (period/duty/phase) ≈ **O(200 numbers TOTAL** for
  all 600 frames → ~150–300 B brotli). The per-frame cost is ~0 (homography from the pose we already pay for).
- **The R²=0.23 resolution:** the failed ego-explanation was a LINEAR regression of pixel positions on 6-dim
  pose. The map is PROJECTIVE (homography) — NONLINEAR. Codec A IS the nonlinear model the linear fit missed.
- **Captures** the fraction f_A of islands that are on-plane painted markings (the bulk). **Fails** off-plane
  (hill crests/banking), occluded, worn/faint, and non-lane class-1 → those go to Codec B or the waterfill tail.
- Cross-ref: #145 (openpilot lane-polynomial + ground-plane homography), #138 (road↔lane IoU gate, done),

## 3. Codec B — sparse WAVELET / CURVELET (robust, larger, high-fidelity; operator's input)
For thin structures Codec A can't model, use a sparse multiscale transform of the class-1 indicator / the
SegNet margin field in the lane band.
- **Wavelets (Daubechies dbN):** an edge image is sparse in wavelets; N-term error O(N⁻¹) for the curve
  singularity. **CURVELETS / shearlets (Candès–Donoho)** are PROVABLY optimal for curves: O(N⁻²(log N)³) — for
  LANE LINES (curves) curvelets ≫ wavelets. This is the "super high fidelity" basis for the thin tail.
- **"large but sparse, design with rare in mind"** = code only the RARE significant coefficients: EZW/SPIHT
  zerotree (Shapiro/Said–Pearlman) — zero-tree the (vast) zeros, arithmetic-code the rare nonzeros + the
  significance map. The codec is tuned for the sparse regime (most coefficients = 0), i.e. the "rare" events.
- **"blob may not compress well"** — blobs (filled regions, area≈length²) have slow wavelet decay → do NOT
  wavelet-code blobs; restrict Codec B to the thin/edge support (the rare significant coefficients).
- **Mallat/Daubechies hierarchical-coarse-gates-fine:** code coarse scales first (smooth boundary), finest
  scale ONLY where significant (the lane coefficients) — a multiresolution waterfill.
- Robust (no lane-geometry model), high-fidelity (places the edge → argmax correct), f_B ≈ 0.9+.

## 4. "as much as is optimal" — the TAIL WATERFILL (the RD truncation)
For each thin structure i (or coefficient, or segment): value `v_i = 100·(pixels_i/N)` [the d_seg it fixes],
cost `c_i` [bytes]. Sort by `v_i/c_i`; code greedily until `v_i/c_i < λ*`, where `λ* = ∂S/∂byte = 25/N`
(the marginal byte value in score units). Per-structure CODEC SELECTION at each step: Codec A where the lane
model fits cheaply (highest v/c), Codec B where it doesn't (robust, pricier), SKIP where v/c < λ* (the
negligible micro-islands: 1–3 px, faint, off-plane — their d_seg < their byte cost). This yields the
**RD-optimal residual d_seg**: capture the structured d_seg-dominant tail, leave the unstructured micro-tail
to the trained generator (or accept it). Deeper λ* (more rate spent) → deeper into the tail → smaller residual.
