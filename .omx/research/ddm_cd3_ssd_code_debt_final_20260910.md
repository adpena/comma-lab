## Gate change: proposed and tested, not applied

`experiments/ddm_vr3_certified_raw_reclaim.py::process_gate` reads `ps ... comm=`, exact-name `pgrep -x`, and lsof process COMMAND/cwd fields. It no longer scans full argv text. An owner token must have boundaries on both sides. Every relevant ps process must have cwd evidence; every lsof cwd process must have a COMMAND. Extra processes first observed by lsof also have their command checked. The short-lived ps observer is accounted for by its command and parent PID. Unknown/malformed records, missing cwd, unavailable ps/pgrep/lsof, and warnings all fail closed.

The inherited sw2 patch incorrectly allowed a self-only cwd census. Review caught and fixed this before packaging. The bz2d journal's ruff argv reference is reproduced by the argv-only fixture; real owner command/cwd controls still refuse. All existing archive/runtime/hash/reference/open-descriptor gates remain in the executor. A complete host process view is still required, so this proposal does not promise that MAIN's apply will pass.
