## ROOT CAUSE of the inertness (a/b/c/d with evidence)

The #75 audit listed candidate causes: (a) precomputed-teacher-KL-with-a-learnable-student-head; (b) the
broken grad regime; (c) EMA/init; (d) a severed YUV6/scorer-preprocess gradient. The B1-clean telemetry
(`/Volumes/VertigoDataTier/pact/b1_229k_clean_20260609T085348Z/telemetry.jsonl`, ep0) localizes it to a
COMPOUND of **(a) + (b)** — NOT (c) and NOT (d):

### (a) CONFIRMED — learnable-student-head KL distill surrogate, not direct-live CE

The MLX harness's default SegNet path (`tac.substrates._shared.mlx_score_aware.loss.score_aware_loss`,
`bundle.distillation_weight > 0` branch, lines 3297-3367) computes
`student_logits = learnable_head(decoded_seg_frame)` and distills KL against a **precomputed teacher logit
cache**. The gradient to the renderer flows `KL -> learnable_head(decoded) -> renderer`. The head is itself
still learning to mimic the SegNet, so the renderer's gradient target is a moving, weakly-coupled surrogate —
NOT the direct CE-through-the-live-SegNet that PR95 uses
(`hnerv_muon/src/stages/common.py:188-191`: `seg_out = distortion_net.segnet(segnet_in);
seg_l = seg_loss_fn(seg_out, gt_argmax)`). The harness comment (loss.py:3315-3324) admits backprop through the
ported SegNet "produces NaN gradients in MLX's second-order autograd" — so it deliberately fell back to the
head surrogate. That surrogate's KL stays ~constant (B1 telemetry `loss_part_distill ≈ 1.59`, flat) while the
exact d_seg never descends. **This is the canonical inactive-objective / Mistake-B bug class.**

### (b) CONFIRMED — a dual-ascent multi-term Lagrangian where pose drowned seg, grad blew up, clip fired 100%

The B1 ep0 telemetry shows the harness ran a HUGE surrogate stack, not PR95's clean `100*seg + 1*pose`:
`pose_distill` (learnable-head pose) + `posenet_yuv6_geometry_tether` + `scorer_input_contrast_floor` +
`scorer_input_shape_tether` + `coder_qat` + a `dual_ascent` Lagrangian over **6 constraints** +
`scorer_space_step_guard` backtracking. The pose surrogate term was **271.30** while the seg surrogate was
**1.59** — pose was ~170× the seg signal. The resulting `gradient_global_norm_pre_clip = 53,425` (rising to
6.8e6 by ep2999) was hard-clipped to 1.0 via `gradient_clip_scale = 1.87e-5` — i.e. EVERY step took a tiny
fraction of a near-pure-pose, near-random direction. The seg gradient (the only thing that moves d_seg) was a
rounding error inside the clipped step. The objective was COMPUTED; the optimization was INERT.

### (c) FALSIFIED as mechanism — EMA/init is fine

PR95 uses the same EMA (decay 0.999) and random/resume init; the fixed loop uses the identical EMA-shadow
pattern and descends. The B1 EMA-best held stage-1 only because there was no descent for it to track, not
because EMA was broken.

### (d) FALSIFIED for B1 — the YUV6 gradient severance was a SEPARATE (already-patched) bug on the POSE axis

The `@torch.no_grad` / in-place upstream `rgb_to_yuv6` severs the PoseNet gradient; PR95's `data.py:51-81`
already patches a differentiable YUV6, and our repo has `tac.differentiable_eval_roundtrip.patch_upstream_yuv6_globally`.
This only affects the pose axis (and B1's pose telemetry was non-zero, so the path was live). It is NOT the
cause of the d_seg wall — d_seg flows through the SegNet RGB path, which has no `@torch.no_grad` severance.
The fixed loop applies the canonical YUV6 patch anyway (so the pose axis is gradient-reachable for #74/#63).

**Verdict: the inertness is (a) the learnable-head distill surrogate substituting for direct-live CE, compounded
by (b) a dual-ascent multi-term Lagrangian whose pose term drowned the seg signal and blew the grad norm into
the hard-clip regime.** The fix removes BOTH: direct CE through the live SegNet + the clean `100*seg + 1*pose`
weighting + a well-scaled grad.

## THE WORKING-LOOP SURFACE (the reusable trainer #74/#63/#65 consume)

`tac.score_aware_loop` — a small, reusable, PR95-faithful score-aware training surface:

| module | role |
|---|---|
| `live_segnet_loss.py` | the PR95 stage losses (CE / tau-softplus / smooth-disagreement / L7-softplus margin) computed ON the live SegNet logits vs GT argmax targets; `pose_loss = sqrt(10*MSE)`; `exact_d_seg_from_logits` (the decisive non-proxy observable). 1:1 port of `hnerv_muon/src/losses.py`. |
| `trainer.py` | `ScoreAwareTrainer` + `ScoreAwareLoopConfig`. Forwards the LIVE frozen scorer on the rendered pair, applies the margin loss vs GT argmax, runs the eval roundtrip (bicubic-up 874x1164 -> bilinear-down 384x512 -> STE round) in the inner loop, aggregates `100*seg + 1*pose`, AdamW (latents 10x) + cosine + grad-clip-1.0, EMA-shadow inference checkpoint. Fails closed if the scorer is not frozen. |
| `targets.py` | `load_frozen_distortion_net` (frozen upstream SegNet+PoseNet, YUV6 patched) + `build_gt_targets` (GT SegNet-argmax + PoseNet targets via `frame_utils.yuv420_to_rgb` only; non-overlapping `seq_len=2` pairs). |
| `tiny_carrier.py` | `TinyPairCarrier` — a minimal per-pair latent->conv carrier for the $0 descent proof (NOT a contest carrier; the *loop* is what ships). |

The decisive observable is `ScoreAwareTrainer.exact_d_seg(use_ema=...)` — the EXACT SegNet argmax-disagreement on
the live render (NOT a proxy, NOT PSNR). A working loop drives it below the ~0.50 mean-field wall; the inert
harness pinned it at 0.5048.

**How #74/#63/#65 consume it:** they instantiate their own carrier (HiNeRV/SNeRV/lever-C smaller renderer),
