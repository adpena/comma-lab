## Full-stack composed representation

### The one-object archive grammar

The new single member is designed in this order:

1. **Header and shared dictionaries:** version, shapes, quantizer exponents, section lengths, deterministic seeds, and hashes required by the receiver. Generic algorithms stay in `inflate.py`; every learned or video-derived value remains counted.
2. **Shared worldsheet program:** a temporally ordered one-graph description of Road-centered class boundaries, topology events, and per-pair coordinates. It predicts a semantic field but is not required to reproduce the old token field losslessly.
3. **Born-with-context semantic field:** warm-lineage renderer plus HPAC-like conditional context jointly trained on the new event field. The entropy model predicts the new quotient symbols, not old F26 tokens.
4. **Joint xi curve:** the same temporal coordinates condition the terminal pose response; additional learned coefficients are stored only where shared coordinates are insufficient.
5. **Exceptions:** sorted topology births/deaths, boundary-cell deviations, and residual values that survived the complete score/byte race. They amend the program; they do not duplicate a dense support mask.
6. **Checksum and deterministic closure:** exact parser exhaustion, field hashes, and repeat identity. The archive remains one member; post-entropy bytes are subjected to the #79 packaging floor rather than blindly recompressed.

This is a hybrid of the shipping semantic-token/HPAC body, the dxi response, G1's worldsheet and G3 event primitives, JO1's exact coupled endpoint, and DC1's decode-compute idea. DC1 constraint shipping is optional: it enters only if a scorer-free compact certificate is smaller than the symbols it removes after its own headers and receiver compute are charged. The 44,244,000 B raw task-cell constraint object is forbidden, and the fixed-grid hash experiment's five-group aggregate loss of 4.9074 ideal-body bytes earns zero projected credit.

**GESTALT-DELTA:** Hybridization means one grammar and one optimization state with shared coordinates, not concatenating five preexisting payloads.
