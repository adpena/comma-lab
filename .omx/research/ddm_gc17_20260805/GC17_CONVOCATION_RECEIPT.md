## Hybrid / Original Route

The original object GC17 recommends is a Weak Stage-1 Packet:

1. free receiver code carries generic DCT, edge/worldsheet solvers, local optimization, and
   deterministic rasterization;
2. counted payload carries only video-derived weak constraints: selected scorer-native buckets,
   edge/worldsheet coordinates, per-pair low-dimensional innovations, and residual rungs;
3. receiver reconstructs a Stage-1 field by solving constraints inside the scorer-equivalence
   box, then applies frame_0 carriage;
4. exact bytes are charged before any scorer survival claim.

This is Bennett's "weakest sufficient constraint, then shortest counted archive" as an engineering
contract. It is not "ignore length": length is minimized inside the legal receiver-feasible set.
