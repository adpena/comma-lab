### B.2 (a) Are they composable onto hv1? NO — four independent reasons

**1. The primary record already says so.** `ddm_mc36_dual_axis_t4_verdict_20260814.md`,

That was written 2026-08-14, about **MC36**. `hv1` is MC36's descendant by two moves, so the
finding binds a fortiori. The "banked pool" framing was written the same day, in `re1`'s verdict,
and did not absorb it.

**2. hv1's admission proof forbids a distortion edit.** hv1 is a *pure rate object on a frozen
distortion*: it re-codes the fixed MC36 token stream and is admitted **only** under exact decoded-
token identity **plus** full raw-output byte identity against the MC36 CPU decode (raw sha
`e5539653f598a1c3…`, 3,662,409,600 B). Its `d_seg` and `d_pose` are *inherited by construction*,
not re-measured. `qs2` changes 189 pixels (−32 flips). `re1` changes 4 pixels (−2 flips). Either
edit **breaks the identity proof that makes hv1's inherited distortion valid.** The composed object
is a new candidate needing its own dual-axis row — not a sum.

**3. `re1`'s object no longer exists.** `re1` is a *probability-object edit* on cp135's probability
object, byte-neutral, changing 4 decoded pixels. `hv1` **replaces the probability object** with a
differently-trained HPAC model. There is no "same edit" to carry across; the analogous edit must be
re-found in the new object. This one is not a re-measurement — it is a re-search.

**4. `qs2` carries a pose compensation solved against a base that is measurably not hv1's.**
`qs2`'s Schur compensation was solved against cp135's realized object at base
`d_pose = 6.885642960696714e-06`. I re-derived hv1's actual pose leg from its primary table:

```
hv1 pose contribution  0.008294576541331089  ->  d_pose 6.88e-06
cp135 base d_pose      6.885642960696714e-06 ->  contribution 0.008297977440736215
difference                                       3.4009e-06 S
```

That gap is **60.9% of the entire bank pool**, and it independently reproduces `pv1`'s measurement
to the digit (`pv1` §3: *"the frontier's d_pose is 6.88e-06, not 6.885642960696714e-06 … Worth
