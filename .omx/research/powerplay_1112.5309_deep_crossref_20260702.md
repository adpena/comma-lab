## What POWERPLAY is (read in full, both halves)
An algorithmic framework for an **open-ended, self-improving problem solver** that *continually invents the simplest still-unsolvable task* and a *solver-modification* that provably solves it **plus all previously learned tasks**, ordered by conditional computational (time & space) complexity given stored experience.

- **Task** `T_i = (I_i, {O_i | J_i}, t_i, n_i)`: input, target/goal-predicate, **TIME bound t_i**, **SPACE bound n_i (bits)**. Solved iff a solver of description length `L(s) < n_i` produces the target within `t_i` steps. A *valid* task may be **"re-solve a prior task T_k with less time/space"** (`t_i < t_k − ε`) — the **"wow-effect": make old skills more efficient.**
- **Variant I** (universal search): order candidate `(T, q)` pairs by `P(p)=2^{−L(p)}` (Solomonoff/MDL prior → **compact, quickly-validated pairs first**); accept the first pair whose **Correctness Demonstration** proves `T` unsolvable by `s_{i-1}`, solvable by `q`, AND all `T_{k<i}` still solvable by `q`.
- **Variant II** (practical, cost-based): aggregate cost **`C(s, TSET) = L(s) + α·Σ_T [t'_s(T) − r(T)]`**; accept `(T_i, s_i)` iff `C(s_{i-1}, T_{≤i}) − C(s_i, T_{≤i}) > ε`. **Forgetting is allowed iff aggregate cost improves.**
- **No-forgetting mechanics:** (a) **prefix-code** `s_i = s_{i-1} ∥ s'_i` (freeze prior, append only) → prior tasks solved by induction, validation reduces to new code; (b) **component-dependency lists `L^k_i`** (which tasks use which component → re-test only affected). "Validation cost need not grow with repertoire."
- **Lineage:** greedy practical creativity theory (compression-progress curiosity), a *feasible* Gödel Machine (drops the global-optimality proof-search for constructibility), OOPS extended to **search problems AND solutions jointly**. Experiments (refs [52,53]) modest: NNs/SLIM-RNNs on invented tasks show **developmental stages + automatic self-modularization + code reuse**, no catastrophic forgetting.
- **Stated risks:** trivial-task-invention (mitigated only by storage pressure + K-complexity bias, not a hard safeguard); **generalization-vs-novelty tension** (a solver that generalizes well is harder to find novel unsolvable tasks for); Correctness-Demonstration cost; non-stationarity inflating task count.
