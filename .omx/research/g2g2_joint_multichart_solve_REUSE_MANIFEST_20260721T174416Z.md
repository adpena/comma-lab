## New-code failed-search justification

Repository search found no existing bounded joint solver that could price and replay multiple decoded LaneLine coefficient addresses while retaining G2CS1's actual 20-byte-first/8-byte-incremental accounting. The predecessor G2g path selected one already-ranked symbol; pixel-space G2f was not the requested alphabet. The smallest extension was therefore a deterministic joint search in the existing predictor module plus a mutually exclusive mode in the existing G2 measurement tool.

No new packet format, rasterizer, scorer, target table, motion constant, or receiver implementation was invented. No frame, full logit tensor, response tensor, or coverage plane was persisted. The response model was explicitly subordinate to actual nonlinear receiver replay.

## Scope and reactivation

The `0/6` negative retires only later prefixes on these measured projected-search paths after their marginal rate stops. It does not retire the LaneLine/chart family. Reactivation requires a materially different formulation—nonlinear multi-chart solving, other decoded chart parameters, or xi-coupled pose—while retaining the same exact receiver, seven predicates, actual byte price, and source/config custody.
