# SO1 design review

Scientific scope: design only. No encoder, model, scorer, renderer or experiment was launched.
The executable-looking block is a command sketch in the memo, not an installed or runtime-tested tool.

## Findings corrected before the final review

* Kept generator-fit debt separate from the final renderer-bias edits; the 48 KB packet premise is
  explicitly counterfactual for an exact GT generator. GF1's actual exact residual remains charged.
* Marked coarse-size scaling and transferred residual rates as assumptions. The two live designs
  have overlapping scenario intervals; no artificial expected-score ranking is claimed.
* Corrected the Lane scenario score to 0.11627060215873829 at the zero-residual grant, before rounding.
* Corrected the command sketch's hash helper: HG1 has no `sha256_file`; the sketch now defines one.
* Added the source search paths required by HG1's bare ET1 import, and pinned both source modules.
* Added field/pointer/source bindings, hashed counts checkpoints, atomic completed decode writes,
  and a real coarse-byte early refusal. These were source reviewed, not runtime tested.
* Avoided HG1's `build_packet`, whose fixed stream IDs and parser describe a different grammar.
  The SO1P envelope is explicitly new, counted, and research only.

## Final source review, pass A

Checked the conservation equation against the parsed RX1M header and actual ZIP stat; checked
both integer endpoints of the sub-0.12 threshold; re-derived dictionary width and sparse support
budget. The atlas share is not treated as a separable Lane-code bill. The old perfect-renderer
axis statement is corrected using move-48 components. The actual timing policy, not raw timeout,
bounds the proposed compute. No additional defect found in this bounded review.

## Final source review, pass B

Read the command sketch end to end: source read-only memmap; current-field histogram target;
decoder-known clamped stencil; independent per-child modes; three-bit table packing/unpacking;
canonical HG1 residual encode/apply pair; real retained compression candidates and repeats;
explicit SO1P header lengths and raw hashes; independent closed field hash; whole-packet gate;
per-stage persisted state. Checked API names against AST/source and parsed the complete block.
Checked every immutable pinned source hash. No additional defect found in this bounded review.

Limits: these are two source reviews, not two empirical passes. No bytes for the proposed
construction, runtime/resume demonstration, new n600 argmax cells, or score were measured.
Resource admission and the governed launcher remain part of the one queued first rung. A byte
pass still requires new receiver integration and timing evidence before any score claim.
