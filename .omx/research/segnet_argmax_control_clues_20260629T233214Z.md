## 0. The problem, grounded on the actual contest code

We must drive the **frozen** SegNet's argmax to the GT class at the eval boundary, using only cheap STORED bytes + a generic decode algorithm (NO scorer weights at inflate time; compress-time SegNet use is LEGAL, README:119).

- **SegNet** = `smp.Unet('tu-efficientnet_b2', classes=5, activation=None, encoder_weights=None)` — `upstream/modules.py:105`. **`encoder_weights=None` ⇒ trained FROM SCRATCH on comma10k**, NOT ImageNet. Input bilinear-resized to 512×384 (`modules.py:109`). d_seg = pure argmax disagreement `(out1.argmax(1) != out2.argmax(1)).float()` (`modules.py:112`).
- **Score** = `100*segnet_dist + sqrt(10*posenet_dist) + 25*rate`, rate = `archive.zip`/uncompressed (`upstream/evaluate.py:92,63`). d_seg weight = 100 → sub-0.15 needs d_seg ≈ 9e-4.
- **R** = render → bicubic↑874×1164 → uint8 → bilinear↓512×384 → frozen CPU-torch SegNet argmax. 96.8% of flip mass is a ~2px boundary band; standard b2 stride-2 stem is blind below ~256×192.
- **Canonical class order** (CLAUDE.md, MEASURED): `0 Road · 1 Lane · 2 Undrivable · 3 Movable · 4 MyCar`.

### THE MEASURED CRUX — R is THREE sub-walls; the binding one is the SegNet read, not the resample
(`r_survival_physics_20260629T182659Z.md`, tool `tools/r_survival_probe.py`, n96; `partition_store_realization_gate_DEFER_20260617T024639Z.md`)

- **Sub-wall (A) resample/uint8 = BENIGN.** Even a naive flat palette survives R to d_seg **< 1e-4** once content is resolved at ≥384 (palette @384 = **5e-5 MEASURED**). The lane (median 2.0px, 76% ≤2px) is above the 384-Nyquist and round-trips intact. **Do not spend bytes fighting R on the resample.**
- **Sub-wall (B) render-resolution/capacity = the SDF's win.** Below 384 a hard/palette carrier box-averages the thin lane away; a **1-Lipschitz SDF survives ~8–10× better** (SDF@192 ≈ hard@384). R is **interpolation-dominant, NOT diffusion** (MEASURED: heat(σ≈1) SDF lane 26.8% loses vs interp@192 3.19% wins); a step label Gibbs-rings under bicubic, an SDF margin is linear → interpolation-exact (Valve-2007 SDF text, `:6232`).
- **Sub-wall (C) the SegNet RGB-read = THE render-role wall.** A stored flat color *survives the pixels* but the frozen SegNet does not *read* it as the partition — this is where "palette ×170–350 death" lives, and it is the binding wall. **MEASURED through the real CPU-torch SegNet** (realization gate): paint the LOSSLESS GT partition (stored d_seg=0) into a camera-res frame → realized d_seg flat GT-mean **0.00811** (boundary flip 25.2%); per-class μ-optimized color **0.00641** (23.6%); even a 50%-GT-*texture* blend only reaches **0.00389** (16.9%). **Mechanism (MEASURED):** the boundary band is **2.25% of pixels** and **~24% flip** because the eval bilinear downsample MIXES the two regions' colors in the 1px seg-grid boundary band → SegNet sees an intermediate color → argmax flips. *"Natural texture barely helps; the resize is the cause."*

**The reframe:** the render-role wall is **(C) sub-pixel boundary-mixing in the bilinear downsample**, NOT the low-pass destroying information and NOT (mainly) off-manifold-ness. The cure is a **render whose boundary is placed sub-pixel so the downsampled color lands on the correct side** — exactly area-coverage anti-aliasing, which a **wide 1-Lipschitz SDF ramp** does for free. `encoder_weights=None` (from-scratch, narrow manifold) makes the read even more boundary/structure-sensitive, reinforcing the geometry lever.
