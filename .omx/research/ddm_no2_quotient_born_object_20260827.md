## 0. Answer first

**The top object is `QBW1`: a signed boundary-event/worldsheet quotient consumed from birth by a
pose-conditioned photometric renderer.** Its alphabet is not a five-class raster and not the binary
question “is HPAC's argmax right?” It is a causally ordered program of oriented inter-class cracks,
region seeds, worldsheet births/deaths, and shared innovations. The decoder integrates those
coordinates into task cells and feeds the same coordinates to a jointly trained renderer. Lane is
therefore generated as a Road-embedded boundary object rather than deleted and bought back as a
carrier. The renderer, not a post-hoc paint operation, owns RGB interiors and pose.

The exact first-rung byte envelope follows directly from the live GB1 block census:

| component | byte envelope | status |
|---|---:|---|
| pose-conditioned renderer | 30,856 B | MEASURED current-body envelope, not a promised QBW1 size |
| terminal pose carrier | 22,010 B | MEASURED current-body envelope; must be freshly re-solved on QBW1 |
| residual + ZIP/RX framing | 96 + 114 B | MEASURED current-body envelope |
| **new quotient program + its model + all headers** | **at most 84,910 B** | DERIVED remainder |
| **complete archive** | **at most 137,986 B** | exact strict fixed-distortion cap |

The 84,910 B line is not a target inferred from entropy. It is the residual of
`137,986 − 30,856 − 22,010 − 96 − 114`. If the new renderer, carrier, framing, model, or any
video-derived side information grows, the quotient allowance shrinks byte-for-byte. Nothing is
free except generic receiver code allowed by rule 118.

**Why this object and not another rate mechanism:** D3 proved that making Lane native to the
alphabet can release 63,928 B, then D3/D3A proved that buying Lane back by repaint destroys Seg and
Pose, and D3B proved that buying it back losslessly erases the rate win. QBW1 removes the delete-and-
reinsert split: the Lane/Road interface is a coordinate of the object, while RGB is realized jointly.
That is the smallest object-level change that confronts every post-08-22 law without contradicting
one.

**The pointer did not move.** The deliverable is one build-ready object, three lower-ranked object
families with exact first gates, and explicit non-reentry rows. Sub-0.12 remains unachieved.

## OPTIMAL FORM

The family reference form is the complete QBW1 mechanism in §6, derived from ES1/IG1's
worldsheet-conditioned quotient, D3's true alphabet change, v14/v15's realization failure, and
FB2's live joint renderer/carrier envelope. There is no prior measured QBW1 implementation whose
score transfers. The reference form therefore requires all of the following simultaneously:

- the real n600 source field and frozen scorers, never synthetic fixtures;
- oriented cracks, region seeds, births/deaths, causal innovations, and native Road↔Lane geometry;
- actual serialized grammar/model/record bytes parsed by the receiver;
- a renderer trained from step zero on quotient coordinates with pose in-loop;
- complete retained primary/repeat packets, render outputs, and per-component scorer rows;
- comparison against a matched GB1 control, with every video-derived artifact counted.

The n32 rung reduces **scope only**: it runs the full mechanism on a seeded random stratified sample
with an explicitly projected population estimator. It does not reduce the alphabet, replace the
receiver with paint, borrow distortion, omit pose, use entropy instead of coder bytes, or shorten the
mechanism's convergence budget. Consequently it can authorize an n600 build but cannot produce a
family verdict or contest score. Any future trainer charter must pin its architecture, optimizer,
stage schedule, convergence rule, and matched-control budget before fire; until that happens the
integration blocker remains `research_only: true` and `ready_for_exact_eval_dispatch=false`.

Provenance pins for every reused scientific component are in §3. The current-body renderer and
terminal carrier are **byte envelopes**, not reusable scored quantities; §5 requires both to be
re-solved and re-measured on QBW1.

   row has no empirical anchor and no full quotient codec was built. No score or feasibility is
   inherited from the design surface.

The bounded search did not find, in these scopes, a receiver-closed quotient-born boundary object

## 5. Common preregistered n32 serialized gate

This is the gate every live family must use. It is specified now so the first build cannot choose a
friendly sample or denominator after seeing results.

### Selection

- source field: 117,964,800-byte decoded token field SHA-256
  `cc10a7b09353c0af1ebe4e52a1640df1fadac4d245a27f41aff8cf0992636efb`;
- seed: `20260827`, NumPy `PCG64`;
- population: pair IDs 0–599, never a prefix;
- strata: ten 60-pair temporal blocks crossed with low/high within-block Road↔Lane crack count;
- crack count: number of horizontal + vertical four-neighbour source-field interfaces whose
  unordered class pair is `{Road, Lane}`; ties are broken by pair ID before the median split;
- allocation: two without-replacement samples from each low/high stratum in temporal blocks 0–5,
  one from each low/high stratum in blocks 6–9, totaling `6*4 + 4*2 = 32`;
- the receipt must list all pair IDs, stratum sizes, inclusion probabilities, and selected crack
  counts. A sample implementation change changes the preregistration and requires a new memo before
  any candidate is run.

BD1's already-observed pairs 16/32/439/454 are diagnostics only and do not alter this new sample.
They may not be force-included.

### Serialized estimator

Each selected pair is encoded as an independently reset variable record so its bytes are
attributable. Shared weights, codebooks, grammar parameters, terminal pose state, headers, model
payloads, and framing are counted once as `B_shared`. For stratum `h`, population size `N_h`, sample
size `n_h`, and exact selected record bytes `b_i`:

```text
B_var_hat = sum_h (N_h / n_h) * sum_{i in sample_h} b_i
B_hat     = B_shared + ceil(B_var_hat)
dseg_hat  = (1/600) * sum_h (N_h / n_h) * sum_i dseg_i
dpose_hat = (1/600) * sum_h (N_h / n_h) * sum_i dpose_i
S_hat     = 100*dseg_hat + sqrt(10*dpose_hat) + 25*B_hat/37,545,489
```

Real coder bytes only. Entropy, model loss, mask IoU, grammar reach, and unparsed projections cannot
occupy `b_i`. If a family relies on temporal coding across selected records, it must report that as
a second diagnostic; it cannot replace the reset-record gate.

### Admission, falsifier, and scope

The first rung is admitted to an n600 retained build only when all are true:

1. independently parsed cells, renderer inputs, and terminal pose payloads match the encoder's
   declared objects exactly;
2. primary and deterministic-repeat packets are byte-identical;
3. a one-bit mutation in every counted section either changes the declared decoded object or refuses;
4. `B_hat <= 137,986 B`;
5. `dpose_hat <= 1.25e-4` through the actual renderer, uint8 path, `R`, and frozen PoseNet;
6. `S_hat < 0.12` using frozen SegNet/PoseNet components recomputed from retained per-pair outputs;
7. the full candidate—not a section—beats its matched GB1 n32 control in complete action.

Any failure closes only the named first-rung formulation. It does not authorize a family KILL. A
pass is also not a score: it authorizes one retained n600 local build, followed by exact contest-axis
evaluation only if the complete n600 archive remains below GB1.

## 6. QBW1 build-ready first rung

### Object and receiver

1. **Quotient coordinates.** Encode oriented Road-hub cracks, region seed labels, boundary
   births/deaths, and causal innovations in time order. Lane is a signed offset/dash event on the
   Road boundary graph, never a standalone mask.
2. **Generic integration.** Free receiver code integrates cracks into cells, verifies closed-chain
   consistency, and rasterizes soft boundary coordinates. It contains no video-derived tables,
   scorer weights, GT, or hard-coded per-pair facts.
3. **Joint realization.** A counted renderer consumes soft cells, boundary tangents, and pose state
   during training and decode. Its interior branch owns luma/photometry; its boundary branch owns
   Seg action. No class-palette overwrite exists.
4. **Pose closure.** The terminal pose state is fitted on the exact QBW1 renderer and counted. A stale
   GB1/BS3 carrier may initialize a solve but may not appear in the measured candidate.
5. **Exceptions.** Residual events enter only after the shared object and are coded in implicit
   traversal order. Explicit `(pair,x,y)` addresses are forbidden in rung 1.

## Observability surface

- **Per-layer inspection:** retain encoder coordinates, integrated cells, renderer boundary/interior
  inputs and outputs, terminal pose state, and final uint8/R outputs for every selected pair.
- **Per-signal decomposition:** `RESULT.json` reports shared and per-record bytes, interface length,
  per-pair/per-stratum `d_seg` and `d_pose`, rate contribution, and complete `S_hat`; it also reports
  Road↔Lane and non-Lane interfaces separately without treating either as a score credit.
- **Run-to-run diff:** the manifest pins git/upstream/source hashes, seed, selected IDs, config,
  stage-checkpoint hashes, packet/repeat hashes, per-section hashes, rendered-frame hashes, and the
  matched GB1 control so two runs can be diffed without inference from stdout.
- **Post-hoc query:** emit append-only JSONL rows for pair/stratum/component facts plus a compact
  `RESULT.json` summary and a section manifest. Every scalar points to its retained producing payload.
- **Cite-chain:** each row carries arm, commit, source-field SHA, upstream snapshot, seed, config SHA,
  hardware/axis, checkpoint SHA, packet SHA, and scorer artifact SHA; local n32 rows are explicitly
  non-authority.
- **Counterfactual hooks:** section-level byte mutation, grammar-branch ablation, Lane-native versus
  separately carried control, joint-render versus fixed-paint control, and boundary/interior branch
  ablations are frozen in the config and reuse the same selected IDs.

### Assumption challenge

The shared assumption across the exhausted table is that a semantic object must first become a
categorical field and only then become RGB. QBW1 violates that backdrop: topology coordinates are
the native conditioning variables of the renderer, and the categorical field is a decoded
observability product, not the rate-bearing state. If that assumption is wrong, v14's fixed-paint
loss transfers and QBW1 fails §5. If it is right, the object can collect Lane's concentration and
the zero-mode mass without paying explicit addresses or repainting pose-bearing interiors.
